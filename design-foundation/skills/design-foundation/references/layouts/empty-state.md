# 空状态页布局模式

**适用**：无数据、无网络、搜索无结果、权限不足、首次使用

---

## 布局结构

```
┌─────────────────────┐
│  导航栏               │
├─────────────────────┤
│                     │
│                     │
│                     │
│    ┌─────────┐      │
│    │         │      │
│    │  插画    │      │  ← 120–160px
│    │  / 图标  │      │
│    │         │      │
│    └─────────┘      │
│                     │
│    标题文案           │  ← 16–18px Semi Bold
│    （一句话说清状态）   │
│                     │
│    说明文案（可选）    │  ← 13–14px 次要色
│    （解释原因或引导）   │
│                     │
│    [ 操作按钮 ]       │  ← 引导用户行动
│                     │
│                     │
├─────────────────────┤
│  TabBar              │
└─────────────────────┘
```

## 组件组合

| 元素 | 组件 | 规格 |
|---|---|---|
| 视觉 | Illustration / Icon | 120–160px，风格匹配（见下方各风格规则） |
| 标题 | BodyText | 16–18px Semi Bold，居中 |
| 说明 | BodyText | 13–14px 次要色，居中，可选 |
| 按钮 | Button | 引导操作（创建/刷新/去设置），可选 |

## 常见空状态类型

| 类型 | 标题示例 | 按钮文案 | 视觉建议 |
|---|---|---|---|
| 无数据 | 「还没有任何内容」 | 「创建第一个」 | 空盒子/文件夹插画 |
| 搜索无结果 | 「没有找到相关内容」 | 「换个关键词试试」 | 放大镜 + 问号 |
| 无网络 | 「网络连接已断开」 | 「重新加载」 | WiFi 断开图标 |
| 权限不足 | 「暂无访问权限」 | 「申请权限」 | 锁图标 |
| 首次使用 | 「欢迎开始使用」 | 「快速上手」 | 火箭/星星插画 |
| 加载失败 | 「加载失败」 | 「重试」 | 断裂的链接/闪电 |

## 间距规则

| 元素 | 间距 |
|---|---|
| 视觉与标题 | 24–32px |
| 标题与说明 | 8–12px |
| 说明与按钮 | 24–32px |
| 整体垂直居中 | 内容区居中显示 |

## 交互要点

- **不要只放文字**：视觉元素（插画/图标）让空状态不枯燥
- **引导行动**：给一个明确的下一步操作按钮
- **不要空白页**：空白页让用户以为出错了
- **文案友好**：不要说「无数据」，说「还没有内容，来创建第一个吧」
