# Dashboard 布局模式

**适用**：数据大盘、管理后台首页、个人工作台、监控面板

---

## 布局结构

```
┌─────────────────────────────────────────┐
│  顶部导航栏（Logo + 搜索 + 用户）          │  ← 56–64px
├──────────┬──────────────────────────────┤
│          │  面包屑 / 页面标题 + 操作按钮   │  ← 48–56px
│  侧边栏  ├──────────────────────────────┤
│  导航    │  ┌────┐ ┌────┐ ┌────┐ ┌────┐│
│  200–    │  │指标│ │指标│ │指标│ │指标││  ← 指标卡行
│  240px   │  │ 1  │ │ 2  │ │ 3  │ │ 4  ││
│          │  └────┘ └────┘ └────┘ └────┘│
│          ├──────────────────────────────┤
│          │  ┌──────────┐ ┌──────────┐  │
│          │  │  图表 1   │ │  图表 2   │  │  ← 图表行（2 列）
│          │  │  折线图   │ │  柱状图   │  │
│          │  └──────────┘ └──────────┘  │
│          ├──────────────────────────────┤
│          │  ┌──────────┐ ┌──────────┐  │
│          │  │  列表 1   │ │  快捷操作 │  │  ← 混合行
│          │  │  最近活动 │ │  常用功能 │  │
│          │  └──────────┘ └──────────┘  │
│          │                              │
└──────────┴──────────────────────────────┘
```

## 组件组合

| 区域 | 组件 | 规格 |
|---|---|---|
| 导航 | SideNav + TopAppBar | 侧边栏可收起（64px 图标模式） |
| 指标卡 | MetricCard | 数字 24–32px Bold + 标签 + 趋势箭头 |
| 图表 | ChartCard | 折线/柱状/饼图，高度 240–320px |
| 列表 | ActivityList | 最近活动/待办，行高 48px |
| 快捷操作 | QuickActions | 4–6 个图标按钮，2×2 或 3×2 网格 |

## 间距规则

| 元素 | 间距 |
|---|---|
| 指标卡之间 | 16px |
| 图表卡片之间 | 16–24px |
| 卡片内边距 | 20–24px |
| 行与行之间 | 24px |

## 响应式断点

| 断点 | 布局变化 |
|---|---|
| S（手机） | 侧边栏隐藏为汉堡菜单，指标卡 1 列，图表全宽堆叠 |
| M（平板） | 侧边栏可收起，指标卡 2 列，图表 1 列 |
| L（桌面） | 侧边栏展开 240px，指标卡 4 列，图表 2 列 |
| XL（大屏） | 指标卡 4 列，图表 2–3 列，可加第 3 列 |

## 交互要点

- **指标卡可点击**：跳转到对应详情页
- **图表可切换**：时间范围（日/周/月/年）、图表类型
- **侧边栏可收起**：图标模式 64px，展开模式 240px
- **数据刷新**：手动刷新按钮 + 自动刷新（可选）
- **拖拽布局**：高级 Dashboard 支持用户自定义卡片位置
