**适用**：App 设置、账号管理、偏好配置、隐私设置

---

## 布局结构（桌面端）

```
┌─────────────────────────────────────────┐
│  顶部导航栏                               │
├──────────────┬──────────────────────────┤
│              │                          │
│  设置侧边栏   │  当前分组内容区            │
│  200–240px   │                          │
│              │  分组标题                   │
│  · 账号      │  ┌────────────────────┐  │
│  · 通知      │  │  设置项 1        ⚙ │  │
│  · 外观      │  ├────────────────────┤  │
│  · 隐私      │  │  设置项 2        ⚙ │  │
│  · 关于      │  ├────────────────────┤  │
│              │  │  设置项 3        › │  │
│              │  └────────────────────┘  │
│              │                          │
└──────────────┴──────────────────────────┘
```

## 组件组合

| 区域 | 组件 | 规格 |
|---|---|---|
| 导航 | TopAppBar | 返回 + 标题 |
| 分组标题 | SectionHeader | 13–14px 次要色，上边距 24px |
| 设置行 | SettingsRow | 图标 + 标签 + 控件（Switch/›/值），行高 52–56px |
| 开关 | Switch | 选中态主色 |
| 选择器 | Select / Picker | 弹出底部面板或右侧页面 |
| 滑块 | Slider | 字体大小/音量等连续值 |
| 危险操作 | DangerButton | 红色文字或红色按钮 |

## 间距规则

| 元素 | 间距 |
|---|---|
| 分组之间 | 24–32px |
| 设置行之间 | 0（用分隔线） |
| 分组标题与第一行 | 8–12px |
| 设置行内边距 | 16px |

## 响应式断点

| 断点 | 布局变化 |
|---|---|
| S（手机） | 单列分组列表，点击设置项弹出底部面板或跳转新页 |
| M（平板） | 单列居中，max-width 600px |
| L/XL（桌面） | 左侧分组导航 240px + 右侧内容区 |

## 交互要点

- **即时生效**：Switch/Slider 改动即时生效，不需要保存按钮
- **确认弹窗**：危险操作（退出登录/删除账号）需二次确认
- **搜索设置**：设置项多时加搜索框
- **分组可折叠**：高级设置可折叠/展开
