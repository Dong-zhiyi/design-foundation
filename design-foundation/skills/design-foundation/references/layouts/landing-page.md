# 落地页布局模式

**适用**：产品官网、活动页、品牌介绍、功能展示

---

## 布局结构

```
┌─────────────────────────────────────────┐
│  导航栏（Logo + 导航 + CTA 按钮）         │  ← 64px
├─────────────────────────────────────────┤
│                                         │
│           Hero 区域                      │  ← 视口高度 80–100%
│                                         │
│     大标题（40–64px Bold）               │
│     副标题（16–20px）                    │
│     [ 主要 CTA 按钮 ]  [ 次要按钮 ]       │
│     产品截图 / 插画                      │
│                                         │
├─────────────────────────────────────────┤
│                                         │
│         社交证明条                        │  ← 80–120px
│   「trusted by」+ Logo 墙（灰度）        │
│                                         │
├─────────────────────────────────────────┤
│                                         │
│         特性展示（3 列）                  │  ← 每区 400–600px 高
│   ┌────┐  ┌────┐  ┌────┐              │
│   │图标│  │图标│  │图标│              │
│   │标题│  │标题│  │标题│              │
│   │描述│  │描述│  │描述│              │
│   └────┘  └────┘  └────┘              │
│                                         │
├─────────────────────────────────────────┤
│                                         │
│         大图 + 文案（交替布局）            │
│   ┌────────┐  ┌──────────┐            │
│   │  图片  │  │  标题     │            │
│   │  50%   │  │  描述     │            │
│   │        │  │  [ 按钮 ] │            │
│   └────────┘  └──────────┘            │
│   （下一组左右互换）                     │
│                                         │
├─────────────────────────────────────────┤
│                                         │
│         用户评价 / 案例                    │
│   ┌──────┐  ┌──────┐  ┌──────┐        │

│                                         │
```

## 组件组合

| 区域 | 组件 | 规格 |
|---|---|---|
| 导航 | TopAppBar | Logo + 导航链接 + CTA 按钮 |
| Hero | HeroSection | 大标题 + 副标题 + CTA + 视觉 |
| 社交证明 | LogoWall | 灰度 Logo 横向排列 |
| 特性 | FeatureCard × 3 | 图标 + 标题 + 描述 |
| 图文 | ImageTextBlock | 图 50% + 文 50%，交替 |
| 评价 | TestimonialCard | 头像 + 评价 + 姓名/职位 |
| 定价 | PricingCard × 3 | 方案名 + 价格 + 功能列表 + CTA |
| CTA | CTASection | 居中大标题 + 按钮 |
| Footer | Footer | 链接分栏 + 社交媒体 + 版权 |

## 间距规则

| 元素 | 间距 |
|---|---|
| 区域之间 | 80–120px（桌面）/ 48–64px（移动） |
| 特性卡片之间 | 24–32px |
| 评价卡片之间 | 16–24px |
| 区域内边距 | 24–48px |

## 响应式断点

| 断点 | 布局变化 |
|---|---|
| S（手机） | 单列堆叠，特性 1 列，评价横向滚动，定价 1 列 |
| M（平板） | 特性 2 列，评价 2 列，定价 2–3 列 |
| L/XL（桌面） | 特性 3 列，评价 3 列，定价 3 列，图文左右并排 |

## 交互要点

- **滚动动画**：区域进入视口时淡入/上滑（可选，尊重 prefers-reduced-motion）
- **导航吸顶**：滚动后导航栏固定顶部
- **平滑滚动**：导航链接锚点平滑滚动到对应区域
- **CTA 突出**：主要 CTA 按钮用主色，全站保持一致
- **性能**：图片懒加载，Hero 区域首屏优先
