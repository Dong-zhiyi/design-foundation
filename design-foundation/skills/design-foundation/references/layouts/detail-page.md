# 详情页布局模式

**适用**：商品详情、文章详情、用户主页、活动详情

---

## 布局结构（移动端）

```
┌─────────────────────┐
│  导航栏（返回+标题+…） │  ← 56px
├─────────────────────┤
│                     │
│    主图/封面区域      │  ← 375×280px（约 4:3）
│    （可轮播）         │
│                     │
├─────────────────────┤
│  标题                 │  ← 18–20px Bold
│  副标题/元信息        │  ← 13–14px 次要色
├─────────────────────┤
│  关键信息块            │  ← 价格/评分/标签
│  （可用 Bento 格）    │
├─────────────────────┤
│  详情内容区            │  ← 富文本/图文混排
│  · 段落 1             │
│  · 段落 2             │
│  · 图片               │
├─────────────────────┤
│  相关推荐（可选）      │  ← 横向滚动卡片
├─────────────────────┤
│  底部操作栏            │  ← 56–64px
│  [收藏] [分享] [购买]  │
└─────────────────────┘
```

## 布局结构（桌面端）

```
┌─────────────────────────────────────────┐
│  顶部导航栏                               │
├─────────────────────────────────────────┤
│                                         │
│  ┌──────────┐  ┌─────────────────────┐  │
│  │          │  │  标题                 │  │
│  │  主图    │  │  副标题/元信息         │  │
│  │  400px   │  │  关键信息块            │  │
│  │  或      │  │  操作按钮组            │  │
│  │  50%     │  │                      │  │
│  │          │  │  详情内容区（窄栏）     │  │
│  └──────────┘  │  max-width 720px      │  │
│                │                      │  │
│                └─────────────────────┘  │
│                                         │
├─────────────────────────────────────────┤
│  相关推荐（3–4 列卡片）                   │
└─────────────────────────────────────────┘
```

## 组件组合

| 区域 | 组件 | 规格 |
|---|---|---|
| 导航 | TopAppBar | 返回 + 标题 + 更多操作 |
| 主图 | ImageCarousel | 4:3 或 1:1，可左右滑动 |
| 标题 | Header + BodyText | 标题 18–20px，副标题 13–14px |
| 信息块 | Card / Tag / Badge | 价格/评分/标签 |
| 内容 | RichText | 段落 + 图片 + 列表 |
| 推荐 | Card（横向滚动） | 3–4 个推荐项 |
| 底部操作 | BottomBar | 固定底部，2–3 个按钮 |

## 间距规则

| 元素 | 间距 |
|---|---|
| 主图与标题 | 16px |
| 标题与副标题 | 4–8px |
| 信息块之间 | 12–16px |
| 内容段落之间 | 16–24px |
| 内容区与相关推荐 | 24–32px |

## 响应式断点

| 断点 | 布局变化 |
|---|---|
| S（手机） | 单列，主图全宽，底部操作栏固定 |
| M（平板） | 主图 50% + 信息 50%，或主图在上信息在下 |
| L/XL（桌面） | 主图左 400px + 信息右，内容区 max-width 720px 居中 |

## 交互要点

- **图片轮播**：支持左右滑动 + 指示点
- **回到顶部**：长内容时浮动按钮
- **分享/收藏**：底部操作栏或导航栏更多菜单
- **锚点导航**：长详情页可用 sticky 目录
