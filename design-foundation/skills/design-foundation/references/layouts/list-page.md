# 列表页布局模式

**适用**：商品列表、文章列表、搜索结果、消息列表、文件列表

---

## 布局结构（移动端）

```
┌─────────────────────┐
│  导航栏（标题+操作）  │  ← 56px
├─────────────────────┤
│  搜索栏（可选）       │  ← 44px
├─────────────────────┤
│  筛选/Tab 栏          │  ← 44px
├─────────────────────┤
│                     │
│  ┌───────────────┐  │
│  │  卡片/行 1     │  │  ← 间距 8–12px
│  └───────────────┘  │
│  ┌───────────────┐  │
│  │  卡片/行 2     │  │
│  └───────────────┘  │
│  ┌───────────────┐  │
│  │  卡片/行 3     │  │
│  └───────────────┘  │
│                     │
├─────────────────────┤
│  加载更多 / 分页     │  ← 48px
├─────────────────────┤
│  TabBar（小程序）    │  ← 98rpx
└─────────────────────┘
```

## 布局结构（桌面端）

```
┌─────────────────────────────────────────┐
│  顶部导航栏                               │  ← 56–64px
├──────────┬──────────────────────────────┤
│          │  搜索栏 + 筛选（可选）          │  ← 48px
│  侧边栏  ├──────────────────────────────┤
│  筛选区  │                              │
│  240px   │  ┌──────┐  ┌──────┐         │
│          │  │卡片 1 │  │卡片 2 │  ...   │
│          │  └──────┘  └──────┘         │
│          │  ┌──────┐  ┌──────┐         │
│          │  │卡片 3 │  │卡片 4 │  ...   │
│          │  └──────┘  └──────┘         │
│          │                              │
├──────────┴──────────────────────────────┤
│  分页器                                   │  ← 48px
└─────────────────────────────────────────┘
```

## 组件组合

| 区域 | 组件 | 规格 |
|---|---|---|
| 导航 | TopAppBar | 标题 + 返回 + 操作按钮 |
| 搜索 | SearchBar | 高 40–44px，圆角按风格 |
| 筛选 | FilterBar / Chip | 横向滚动，选中态明显 |
| 列表项 | Card / ListItem | 卡片式或行式，间距 8–12px |
| 加载 | Spinner / Skeleton | 底部加载或骨架屏 |
| 空态 | EmptyState | 无数据时展示 |

## 间距规则

| 元素 | 间距 |
|---|---|
| 卡片之间 | 8–12px |
| 卡片内边距 | 12–16px |
| 列表项之间 | 0（用分隔线）或 8px |
| 筛选栏与列表 | 8–16px |

## 响应式断点

| 断点 | 列数 | 布局变化 |
|---|---|---|
| S（手机） | 1 列 | 卡片全宽，筛选在顶部横向滚动 |
| M（平板） | 2 列 | 卡片两列，筛选可展开 |
| L/XL（桌面） | 3–4 列 | 筛选移至左侧边栏 240px |

## 交互要点

- **下拉刷新**：移动端必备
- **上拉加载**：触底自动加载或「加载更多」按钮
- **筛选联动**：筛选条件变化时列表即时刷新
- **骨架屏**：首次加载用骨架屏，不要用空白
