# 表单页布局模式

**适用**：注册/登录、新建/编辑、设置表单、反馈/联系

---

## 布局结构（移动端）

```
┌─────────────────────┐
│  导航栏（返回+标题）   │  ← 56px
├─────────────────────┤
│                     │
│  标题/说明（可选）     │  ← 20–24px Bold
│                     │
├─────────────────────┤
│  字段组 1             │
│  ┌───────────────┐  │
│  │  Label         │  │  ← 13–14px Medium
│  │  Input Field   │  │  ← 高 44–48px
│  │  Helper text   │  │  ← 12px 次要色
│  └───────────────┘  │
│                     │
│  字段组 2             │
│  ┌───────────────┐  │
│  │  Label         │  │
│  │  Select/Drop   │  │
│  └───────────────┘  │
│                     │
│  字段组 3（多行）     │
│  ┌───────────────┐  │
│  │  Label         │  │
│  │  Textarea      │  │  ← 高 80–120px
│  └───────────────┘  │
│                     │
│  复选/开关（可选）    │
│  ☑ 同意服务条款      │
│                     │
├─────────────────────┤
│  提交按钮（全宽）     │  ← 高 48px
│  [ 提 交 ]           │
└─────────────────────┘
```

## 布局结构（桌面端）

```
┌─────────────────────────────────────────┐
│  顶部导航栏                               │
├─────────────────────────────────────────┤
│                                         │
│         表单容器（max-width 560px）       │
│         居中显示                         │
│                                         │
│  标题/说明                                │
│                                         │
│  ┌─────────────────────────────────┐    │
│  │  Label                           │    │
│  │  Input Field（全宽）              │    │
│  │  Helper text                     │    │
│  └─────────────────────────────────┘    │
│                                         │
│  ┌──────────────┐  ┌──────────────┐    │
│  │  字段 A（50%） │  │  字段 B（50%） │    │  ← 并排字段
│  └──────────────┘  └──────────────┘    │
│                                         │
│  ┌─────────────────────────────────┐    │
│  │  Textarea（全宽）                 │    │
│  └─────────────────────────────────┘    │
│                                         │
│  [ 取消 ]  [ 提 交 ]                     │  ← 右对齐
│                                         │
└─────────────────────────────────────────┘
```

## 组件组合

| 区域 | 组件 | 规格 |
|---|---|---|
| 标题 | Header + BodyText | 说明文字 14–16px 次要色 |
| 输入框 | TextField | 高 44–48px，圆角按风格 |
| 下拉选择 | Select / Dropdown | 同输入框高度 |
| 多行文本 | Textarea | 高 80–120px |
| 复选/单选 | Checkbox / RadioButton | 热区 ≥44px |
| 开关 | Switch | 选中态用主色 |
| 日期选择 | DatePicker | 弹出面板 |
| 文件上传 | FileUpload | 拖拽区或按钮 |
| 提交 | Button（全宽/右对齐） | 高 48px |

## 间距规则

| 元素 | 间距 |
|---|---|
| 字段组之间 | 20–24px |
| Label 与输入框 | 6–8px |
| 输入框与 Helper | 4–6px |
| 按钮组之间 | 12–16px |
| 表单容器内边距 | 24–32px |

## 响应式断点

| 断点 | 布局变化 |
|---|---|
| S（手机） | 单列，所有字段全宽，提交按钮全宽固定底部 |
| M（平板） | 单列居中，max-width 560px |
| L/XL（桌面） | 短字段可并排（50% + 50%），提交按钮右对齐 |

## 交互要点

- **实时校验**：失焦时校验，错误即时显示（红色文字 + 边框）
- **必填标记**：Label 前加 `*` 或「必填」标签
- **密码可见**：输入框右侧眼睛图标切换
- **自动填充**：支持浏览器/系统自动填充
- **提交反馈**：加载中禁用按钮 + Spinner，成功后 Toast/跳转
- **分步表单**：字段多时用 Step 指示器（步骤 1/2/3）
