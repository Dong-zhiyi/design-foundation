# 搜索结果页布局模式

**适用**：站内搜索、筛选结果、全局搜索

---

## 布局结构（移动端）

```
┌─────────────────────┐
│  搜索栏（固定顶部）    │  ← 44–48px
│  [🔍 关键词    ×]    │
├─────────────────────┤
│  筛选/分类 Tab        │  ← 44px（横向滚动）
│  [全部] [文章] [商品] │
├─────────────────────┤
│  结果计数              │  ← 13px 次要色
│  「找到 42 条结果」    │
├─────────────────────┤
│                     │
│  ┌───────────────┐  │
│  │  结果项 1      │  │  ← 行高 64–72px
│  │  标题 + 摘要   │  │
│  └───────────────┘  │
│  ┌───────────────┐  │
│  │  结果项 2      │  │
│  └───────────────┘  │
│  ┌───────────────┐  │
│  │  结果项 3      │  │
│  └───────────────┘  │
│                     │
├─────────────────────┤
│  加载更多 / 分页     │
└─────────────────────┘
```

## 布局结构（桌面端）

```
┌─────────────────────────────────────────┐
│  顶部导航栏 + 搜索栏（居中，max 600px）   │
├─────────────────────────────────────────┤
│                                         │
│  筛选栏（横向）：分类 + 排序 + 更多筛选   │  ← 48px
│  [全部] [文章] [商品]  排序: 相关度 ▾    │
│                                         │
├──────────┬──────────────────────────────┤
│          │  结果计数：「找到 42 条结果」   │
│  侧边栏  │                              │
│  筛选区  │  ┌────────────────────────┐  │
│  240px   │  │  结果项 1               │  │
│          │  │  标题 + 摘要 + 元信息    │  │
│  · 分类  │  └────────────────────────┘  │
│  · 价格  │  ┌────────────────────────┐  │
│  · 品牌  │  │  结果项 2               │  │
│  · 评分  │  └────────────────────────┘  │
│          │                              │
│          │  分页器：‹ 1 2 3 4 5 ›       │
└──────────┴──────────────────────────────┘
```

## 组件组合

| 区域 | 组件 | 规格 |
|---|---|---|
| 搜索栏 | SearchBar | 固定顶部，支持清除和搜索历史 |
| 筛选 | FilterBar / Chip | 横向滚动（移动）或侧边栏（桌面） |
| 排序 | Select / Dropdown | 相关度/最新/价格 |
| 结果项 | SearchResultItem | 标题 + 摘要 + 元信息（时间/来源/标签） |
| 高亮 | Mark | 关键词高亮（主色背景或加粗） |
| 分页 | Pagination | 页码 + 上一页/下一页 |
| 无结果 | EmptyState | 插画 + 文案 + 建议 |

## 间距规则

| 元素 | 间距 |
|---|---|
| 结果项之间 | 0（分隔线）或 12px |
| 结果项内边距 | 16px |
| 筛选栏与结果 | 8–16px |
| 关键词高亮 | 背景色块，圆角 2px |

## 响应式断点

| 断点 | 布局变化 |
|---|---|
| S（手机） | 单列，筛选横向滚动 Tab，结果全宽 |
| M（平板） | 单列居中，筛选可展开为面板 |
| L/XL（桌面） | 筛选移至左侧边栏 240px，结果区 max-width 800px |

## 交互要点

- **搜索建议**：输入时实时显示建议（防抖 300ms）
- **搜索历史**：保存最近 5–10 条搜索记录
- **关键词高亮**：结果中匹配的关键词加粗或高亮背景
- **筛选即时生效**：切换筛选条件时结果即时刷新
- **无结果引导**：提供拼写建议、放宽筛选、热门搜索
- **加载状态**：搜索中显示骨架屏或 Spinner
