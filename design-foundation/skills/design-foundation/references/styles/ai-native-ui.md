# AI Native UI

**调性**：对话优先、留白充足、轻动画、信任感，为「人和 AI 协作」而生。

**适用场景**：AI 对话产品、Copilot 类工具、AI Agent 界面、生成式产品

**不适用**：传统工具后台、强内容消费产品

**来源**：`yanliudesign/design-style-skill`（AI Native UI / Conversational UI）、`MKAbuMattar/uidesign`

---

## 色板

| 角色 | 色值 | 用途 |
|---|---|---|
| 背景色 | `#FFFFFF`（浅）/ `#0D0D0F`（深） | 画布 |
| 表面色 | `#F7F7F8` / `#16161A` | 消息气泡、卡片 |
| 主要文字 | `#111111` / `#E8E8EC` | 正文 |
| 次要文字 | `#6B7280` / `#8A8A96` | 提示、时间戳 |
| 主色 | `#10A37F`（OpenAI 绿）/ `#5E6AD2`（蓝紫）/ 品牌色 | 主要操作、AI 标识 |
| 强调 | 渐变（同色系） | AI 生成区域、高亮 |
| 描边 | `#E5E7EB` / `#2A2A32` | 分隔 |

**对比度自检**：次要文字档需实测，AI 界面常有大量次要文字

---

## 字体

| 用途 | 字体 | 字号 | 字重 |
|---|---|---|---|
| 标题 | Inter / Geist / SF Pro | 20–28 | Semi Bold |
| 正文（用户） | Inter | 15–16 | Regular |
| 正文（AI） | Inter | 15–16 | Regular |
| 代码 | JetBrains Mono | 13–14 | Regular |
| 辅助 | Inter | 12–13 | Regular |

**要点**：**用户消息和 AI 消息在视觉上要能区分**（靠位置/背景，不靠颜色刺眼）。

---

## 形状与质感

| 项目 | 数值 |
|---|---|
| 圆角 | 中（12–16px），气泡 16–20px |
| 阴影 | 极轻或无 |
| 边框 | 1px 细线或无色 |
| 质感 | 扁平；AI 生成区可用**极轻微渐变**或**呼吸动画** |

---

## 布局规则

- **对话流**为主：消息按时间线排列，最新在底部
- 输入区**固定在底部**（全宽、可生长）
- 侧边栏放会话历史（可收起）
- 间距：16 / 20 / 24
- 信息密度：适中（对话界面不宜过挤）

---

## 组件要点

| 组件 | 规格 |
|---|---|
| 消息气泡 | 圆角 16–20px，浅灰底（AI）/ 主色底（用户） |
| 输入框 | 底部全宽，圆角 20–24px，支持多行生长 |
| 发送按钮 | 圆形，主色，右下 |
| 代码块 | 等宽字体 + 语法高亮 + 复制按钮 |
| 工具调用卡 | 折叠式，显示 AI 正在做什么 |
| 流式输出 | 光标闪烁 / 逐字出现（可降级） |
| 引用/来源 | 小号卡片，可展开 |

---

## 反模式（不要这样做）

- ❌ 用户和 AI 消息视觉混淆（必须有明显区分）
- ❌ 用刺眼颜色区分角色
- ❌ 生成中没有任何反馈（要有流式/骨架）
- ❌ 输入框太小或位置不固定
- ❌ 过度拟人化（大头像、表情）

---

## 平台适配提示

| 平台 | 注意事项 |
|---|---|
| 微信小程序 | AI 对话类小程序增多；输入区要避让 TabBar 98rpx |
| iOS App | 注意键盘弹起时的布局 |
| Android App | 同上 |
| 网站 | **最佳平台**，侧边栏 + 对话流最自然 |

---

## 动效与动画

| 项目 | 规格 |
|---|---|
| 过渡曲线 | ease |
| 过渡时长 | 中（200ms） |
| hover 效果 | 轻微阴影（`0 1px 3px` → `0 2px 8px`） |
| 页面切换 | 滑动（新消息从底部滑入） |
| 加载动画 | 流式打字（逐字出现）+ 光标闪烁 |
| 特殊动效 | AI 生成区呼吸光效（极轻微 opacity 脉冲），工具调用卡折叠/展开 |

**要点**：动效服务于「对话流」——消息进入要自然，生成过程要有反馈，但不打断阅读。
