# 柔 UI（Neumorphism）

**调性**：低对比、同色系、软凹凸，安静、克制、有「未来感」。

**适用场景**：控制面板、音乐播放器、设置页、仪表盘、小众工具

**不适用**：内容型产品、无障碍要求高的场景、户外强光环境、需要强层级的界面

**来源**：`MKAbuMattar/uidesign`、`yanliudesign/design-style-skill`（Neumorphism）

> ⚠️ **可读性是最大风险**。低对比是风格特征，但也意味着**必须严格测对比度**。

---

## 色板

| 角色 | 色值 | 用途 |
|---|---|---|
| 背景色 | `#E0E5EC` | **唯一底色**，所有元素都基于它 |
| 表面色 | `#E0E5EC`（同底色） | 用阴影区分，不用颜色 |
| 凸起元素 | `#E0E5EC` + 亮暗双阴影 | 按钮、卡片 |
| 凹陷元素 | `#E0E5EC` + 反向阴影 | 输入框、开关槽 |
| 主要文字 | `#3A4356` | 标题 |
| 次要文字 | `#8A94A8` | 辅助 |
| 强调色 | `#6C8CFF` | 选中、激活 |

**对比度自检**：`#8A94A8` on `#E0E5EC` ≈ 2.8:1 ❌ **不达 AA**，仅可用于大字号或装饰

---

## 字体

| 用途 | 字体 | 字号 | 字重 |
|---|---|---|---|
| 标题 | Inter / SF Pro | 20–28 | Semi Bold |
| 正文 | Inter | 14–16 | Regular |
| 辅助 | Inter | 12–13 | Regular |

**要点**：字体颜色**不能太深**（否则破坏柔和感），但也不能太浅（可读性）——这个平衡很难，务必实测。

---

## 形状与质感

| 项目 | 数值 |
|---|---|
| 圆角 | 大（16–24px） |
| 阴影 | **成对使用**：亮阴影（左上）+ 暗阴影（右下） |
| 边框 | 无 |
| 质感 | 柔和的「挤出」感 |

**典型阴影**：
```css
/* 凸起 */
box-shadow: 8px 8px 16px #B8BEC9, -8px -8px 16px #FFFFFF;
/* 凹陷 */
box-shadow: inset 6px 6px 12px #B8BEC9, inset -6px -6px 12px #FFFFFF;
```

---

## 布局规则

- 背景**纯色**，不要渐变或图片
- 所有元素**同色系**
- 间距：16 / 24 / 32
- 信息密度：低
- 圆角统一大

---

## 组件要点

| 组件 | 规格 |
|---|---|
| 按钮 | 圆角 16px，双阴影；按下时变凹陷（inset） |
| 卡片 | 圆角 20px，双阴影 |
| 开关 | 凸起轨道 + 凸起圆形滑块（选中时变色） |
| 输入框 | **凹陷**（inset 阴影） |
| 图标 | 线性 1.5px，颜色与文字一致 |

---

## 反模式（不要这样做）

- ❌ **对比度不足用于正文**（必须 ≥4.5:1）
- ❌ 加边框（破坏柔和感）
- ❌ 深色背景（Neumorphism 基本只做浅色）
- ❌ 大面积使用（视觉疲劳）
- ❌ 用于需要快速扫读的列表

---

## 平台适配提示

| 平台 | 注意事项 |
|---|---|
| 微信小程序 | 双阴影性能一般；控件热区要够 |
| iOS App | 配合系统深色需重做一套（成本高） |
| Android App | 同上 |
| 网站 | 最适合，但要做 `prefers-contrast: more` 降级 |

**无障碍降级**：提供 `prefers-contrast: more` 版本，把次要文字加深到 `#4A5468`。

---

## 动效与动画

| 项目 | 规格 |
|---|---|
| 过渡曲线 | ease |
| 过渡时长 | 中（250ms） |
| hover 效果 | 凸起变凹陷（阴影反转），模拟「按下」 |
| 页面切换 | 淡入（200ms） |
| 加载动画 | 脉冲凹陷（inset 阴影呼吸） |
| 特殊动效 | 开关切换：滑块平滑移动 + 轨道颜色渐变 |

**要点**：动效围绕「凹凸转换」展开，所有交互都要有触感反馈。

## 生成指令摘要

> 背景**唯一色** `#E0E5EC`，所有元素同色系，**不用颜色区分层级，只用阴影**。凸起元素：双阴影（亮 `#FFFFFF` 左上 + 暗 `#B8BEC9` 右下）；凹陷元素（输入框）：反向 inset 阴影。圆角大（16–24px），不用描边。文字 `#3A4356`（主）/ `#8A94A8`（次，仅大字号），强调 `#6C8CFF`。⚠️ 次要文字对比度仅 2.8:1，正文必须加深到 ≥4.5:1。按钮按下变凹陷（inset）。
