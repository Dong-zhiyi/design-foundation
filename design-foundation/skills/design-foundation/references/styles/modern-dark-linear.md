# 现代深色 / Linear 风

**调性**：深色背景 + 低饱和表面 + 单一高亮色，克制、精确、有「工具感」。

**适用场景**：开发者工具、SaaS 后台、数据产品、AI 产品、效率工具

**不适用**：内容阅读型（深色长时间阅读累）、儿童产品、传统行业（金融/政务需谨慎）

**来源**：`ddddddps/claude-ui-style-skill`（Linear 条目）、`nicohodt/claude-code-ui-ux-skill`（Dark Tech / Linear Style）

---

## 色板

| 角色 | 色值 | 用途 |
|---|---|---|
| 主色 | `#5E6AD2`（蓝紫）或 `#22C55E`（绿） | 主要操作、高亮 |
| 背景色 | `#0D0D0F` | 最深底色 |
| 表面色 1 | `#16161A` | 卡片 |
| 表面色 2 | `#1E1E24` | 浮层、输入框 |
| 主要文字 | `#E8E8EC` | 标题正文 |
| 次要文字 | `#8A8A96` | 辅助说明 |
| 描边 | `#2A2A32` | 边框分隔 |
| 强调 | `#F5F5F7` | 高对比文字 |

**对比度自检**：`#8A8A96` on `#16161A` ≈ 5.1:1 ✅

---

## 字体

| 用途 | 字体 | 字号 | 字重 |
|---|---|---|---|
| 大标题 | Inter / Geist | 28–36 | Semi Bold |
| 标题 | Inter / Geist | 16–20 | Medium |
| 正文 | Inter / Geist | 13–14 | Regular |
| 辅助 | Inter / Geist | 12 | Regular |

**要点**：字号整体偏小（13–14px 正文），靠**字重和颜色**区分层级，不靠字号。

---

## 形状与质感

| 项目 | 数值 |
|---|---|
| 圆角 | 小（6–8px） |
| 阴影 | 几乎不用，用描边和色差分层 |
| 边框 | 1px `#2A2A32` |
| 质感 | 扁平 + 微妙渐变 + 极轻模糊（毛玻璃用于浮层） |

---

## 布局规则

- 间距体系：4 / 8 / 12 / 16 / 24
- 信息密度：**高**（深色 + 小字号可以承载更多信息）
- 对齐：严格左对齐，网格严谨
- 栅格：后台用侧边栏 + 内容区；工具用顶栏 + 主区
- 强调：**一个界面只有一个高亮色**

---

## 组件要点

| 组件 | 规格 |
|---|---|
| 按钮 | 高 32–36px，圆角 6px，主色底白字；次要按钮描边 |
| 卡片 | 圆角 8px，`#16161A` 底，1px 描边 |
| 导航 | 左侧边栏 240px 或顶部导航 56px |
| 图标 | 线性 1.5–2px，16–20px |
| 输入框 | 高 32px，圆角 6px，`#1E1E24` 底 + 描边 |
| 表格 | 行高 40px，hover 高亮行 |

---

## 反模式（不要这样做）

- ❌ 多种高亮色混用（会失去克制感）
- ❌ 大面积纯黑 `#000`（用 `#0D0D0F` 更柔和）
- ❌ 重阴影（深色下阴影几乎看不见，用描边分层）
- ❌ 彩色渐变滥用（最多一处）
- ❌ 正文用纯白（刺眼，用 `#E8E8EC`）

---

## 平台适配提示

| 平台 | 注意事项 |
|---|---|
| 微信小程序 | **不支持全局深色**，需页面级适配；胶囊配色选 `white` |
| iOS App | 用 `systemBackground` 语义色，跟随系统深色 |
| Android App | 用 Material 3 dark tonal palette |
| 网站 | 首选平台，天然适合；注意 `prefers-color-scheme` |
