# Bento Grid

**调性**：圆角方块拼成的网格，像便当盒，模块化、清晰、有秩序感。

**适用场景**：功能入口页、Dashboard、产品介绍页、AI 产品首页、个人工作台

**不适用**：强内容叙事、线性流程（表单/结算）、需要强视觉冲击的活动页

**来源**：`nicohodt/claude-code-ui-ux-skill`（Bento Grid）、`yanliudesign/design-style-skill`

> 名字来自 Apple 的 Bento Box 宣传图，2024 年后成为主流布局范式。

---

## 色板

| 角色 | 色值 | 用途 |
|---|---|---|
| 背景色 | `#0A0A0A`（深色版）或 `#F5F5F7`（浅色版） | 画布 |
| 格子色 | `#1C1C1E`（深）/ `#FFFFFF`（浅） | 每个 bento 格 |
| 主要文字 | `#FFFFFF` / `#111111` | 标题 |
| 次要文字 | `#8A8A96` / `#6B7280` | 辅助 |
| 强调色 | 每格可不同（渐变/品牌色） | 图标、数据高亮 |
| 描边 | `#2A2A32` / `#E5E7EB` | 格子边框 |

**对比度自检**：深色版 `#8A8A96` on `#1C1C1E` ≈ 5.1:1 ✅

---

## 字体

| 用途 | 字体 | 字号 | 字重 |
|---|---|---|---|
| 大标题 | Inter / SF Pro | 32–48 | Bold |
| 格内标题 | Inter | 16–20 | Semi Bold |
| 格内数据 | Inter / 等宽字体 | 24–40 | Bold |
| 辅助 | Inter | 12–13 | Regular |

**要点**：数字/数据可以**特别大**，形成视觉焦点。

---

## 形状与质感

| 项目 | 数值 |
|---|---|
| 圆角 | **大（20–28px）**，格子间圆角要协调 |
| 阴影 | 极轻或无（用描边或色差分层） |
| 边框 | 1px 描边（深色版）或无（浅色版） |
| 质感 | 扁平，可加轻微渐变 |

---

## 布局规则

- **网格**：通常是 12 栏或 CSS Grid
- 格子**大小不等**（1×1、2×1、2×2），形成节奏
- **格子间距**：12–16px（间隙也是设计的一部分）
- 响应式：大屏 4 列 → 中屏 2 列 → 小屏 1 列
- 每个格子内部：**一个主题 + 一个焦点**

---

## 组件要点

| 组件 | 规格 |
|---|---|
| Bento 格 | 圆角 24px，内边距 20–24px |
| 图标 | 面性或 3D，可大至 40–64px |
| 按钮 | 格内通栏或右侧小按钮 |
| 数据展示 | 大字号 + 趋势色（绿涨红跌） |
| 图表 | 迷你图（sparkline），高度 40–80px |

---

## 反模式（不要这样做）

- ❌ 所有格子一样大（失去节奏感）
- ❌ 格子间距不一致
- ❌ 一个格子塞太多内容
- ❌ 圆角大小不统一
- ❌ 响应式直接堆叠（要重排，不是简单变一列）

---

## 平台适配提示

| 平台 | 注意事项 |
|---|---|
| 微信小程序 | 网格用 rpx；注意首屏加载性能 |
| iOS App | 天然契合（Apple 带火的） |
| Android App | 契合，注意圆角与 Material 差异 |
| 网站 | **最佳平台**，大屏能发挥网格优势 |

---

## 动效与动画

| 项目 | 规格 |
|---|---|
| 过渡曲线 | ease |
| 过渡时长 | 中（200ms） |
| hover 效果 | 格子轻微上浮（translateY -2px）+ 阴影微增 |
| 页面切换 | 淡入 + 轻微缩放（0.98 → 1.0） |
| 加载动画 | 骨架屏（格子轮廓脉动） |
| 特殊动效 | 数据更新时数字滚动（count-up），趋势箭头动画 |

**要点**：动效服务于模块化节奏，每个格子独立响应，不联动。
