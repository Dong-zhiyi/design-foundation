# 经典剧院（红金）

**调性**：深红 + 烫金，庄重、有仪式感，带古典戏剧的厚重与华丽。

**适用场景**：剧院 / 演出票务 / 文博 / 高端品牌 / 节庆活动 / 需要「仪式感」的页面

**不适用**：工具类产品、后台系统、内容密集型产品、儿童向

**来源**：配色逻辑参考 `cumabozkurt/god-of-design` 的 Art Deco / Victorian 条目。

---

## 色板

| 角色 | 色值 | 用途 |
|---|---|---|
| 主色 | `#8C1D18` | 品牌、主要操作、导航 |
| 深主色 | `#4A0B08` | Header 背景、深色块 |
| 强调色 | `#C9A227` | 金，点缀、按钮、高亮 |
| 背景色 | `#FAF7F2` | 米白画布 |
| 表面色 | `#FFFFFF` | 卡片 |
| 主要文字 | `#1A1A1A` | 标题正文 |
| 次要文字 | `#6B6B6B` | 辅助说明 |
| 描边 | `#E8DFD2` | 边框分隔 |
| 深色版背景 | `#1A1210` | 深色模式 |

**对比度自检**：`#6B6B6B` on `#FFFFFF` ≈ 4.9:1 ✅；`#C9A227` on `#8C1D18` ≈ 5.2:1 ✅

---

## 字体

| 用途 | 字体 | 字号 | 字重 |
|---|---|---|---|
| 大标题 | 宋体/思源宋体 或 Inter | 26–32 | Bold |
| 标题 | Inter / 思源黑体 | 18–22 | Semi Bold |
| 正文 | Inter / 思源黑体 | 14–16 | Regular |
| 辅助 | Inter / 思源黑体 | 12 | Regular |

**要点**：中文标题用**宋体/衬线**能立刻建立古典感；正文用无衬线保证可读性。

---

## 形状与质感

| 项目 | 数值 |
|---|---|
| 圆角 | 中（12px），按钮可用全圆 |
| 阴影 | 轻（`0 8px 20px rgba(0,0,0,0.28)`） |
| 边框 | 1px 描边或金线分隔 |
| 质感 | 扁平 + 渐变（深红→金）+ 装饰性圆环 |

---

## 布局规则

- 移动端：单列，边距 16px
- 间距体系：4 / 8 / 12 / 16 / 24 / 32
- 信息密度：适中偏宽松（留白营造仪式感）
- 对齐：左对齐为主，Banner 可居中
- 图片比例：海报 3:4 或 2:3；Banner 约 2.9:1
- 装饰：金色圆环、细线分隔、衬线标题

---

## 组件要点

| 组件 | 规格 |
|---|---|
| 按钮 | 高 44–48px，圆角 24px（全圆），金底深字 |
| 卡片 | 圆角 12px，白底，轻阴影 |
| 导航 | 顶部深红 Header 128rpx（小程序）；底部 TabBar 98rpx |
| 图标 | 线性 1.8px，24px |
| 标签 | 高 18px，圆角 4px，浅金底 + 深红字 |
| Banner | 圆角 16px，渐变背景 + 装饰圆环 + 轮播点 |

---

## 反模式（不要这样做）

- ❌ 金色大面积铺底（会显得俗气，金色只做点缀）
- ❌ 深红 + 高饱和撞色（破坏庄重感）
- ❌ 圆角过大（削弱古典感）
- ❌ 正文用衬线字体（小字号可读性差）
- ❌ 加无关的动效（闪烁、弹跳）

## 平台适配提示

| 平台 | 注意事项 |
|---|---|
| 微信小程序 | 导航栏 128rpx 用深红；胶囊区域必须避让；TabBar 98rpx |
| iOS App | Safe Area 内边距加大；Header 可用毛玻璃 |
| Android App | 同 iOS，注意状态栏颜色 |
| 网站 | 可用更大字号和更多留白；Banner 可做全宽 |
