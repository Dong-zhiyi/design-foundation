# 终端 / 数据密集（Terminal / Data-Dense）

**调性**：等宽字体、字符界面、无装饰、信息密度极高，极客感、专业感。

**适用场景**：开发者工具、数据库客户端、监控大盘、命令行产品、日志/分析平台

**不适用**：面向普通用户的产品、内容阅读、移动端（小屏难以承载）

**来源**：`luogao/design-atlas`（Terminal & TUI 分类）、`nicohodt/claude-code-ui-ux-skill`（Terminal / Data-Dense）

---

## 色板

| 角色 | 色值 | 用途 |
|---|---|---|
| 背景色 | `#0D1117`（GitHub 深色）/ `#000000` | 画布 |
| 表面色 | `#161B22` | 面板 |
| 主要文字 | `#C9D1D9` | 正文 |
| 次要文字 | `#8B949E` | 注释 |
| 描边 | `#30363D` | 边框 |
| 成功 | `#3FB950` | 通过 |
| 警告 | `#D29922` | 警告 |
| 错误 | `#F85149` | 错误 |
| 信息 | `#58A6FF` | 链接、高亮 |

**对比度自检**：`#8B949E` on `#0D1117` ≈ 5.6:1 ✅

---

## 字体

| 用途 | 字体 | 字号 | 字重 |
|---|---|---|---|
| 全部 | **等宽字体**（JetBrains Mono / IBM Plex Mono / Cascadia Code） | 12–14 | Regular |
| 标题 | 等宽 | 16–20 | Bold |
| 代码 | 等宽 | 12–13 | Regular |

**要点**：**全站等宽**是核心特征。等宽字体让字符对齐，适合表格和数据。

---

## 形状与质感

| 项目 | 数值 |
|---|---|
| 圆角 | **0 或极小（2–4px）** |
| 阴影 | 无 |
| 边框 | 1px 实线，**ASCII 字符边框**（`+---+`、`│`）可选 |
| 质感 | 完全扁平，可用 ASCII 艺术装饰 |

---

## 布局规则

- **信息密度极高**（这是风格的一部分）
- 用**表格、列表、树形**组织信息
- 用**颜色**区分类别（语法高亮逻辑）
- 分栏：侧边树 + 主内容 + 底部状态栏
- 状态栏显示：行号、列号、分支、编码、时间

---

## 组件要点

| 组件 | 规格 |
|---|---|
| 表格 | 行高 28–32px，等宽对齐，无斑马纹 |
| 按钮 | 矩形，1px 边框，等宽文字 |
| 输入框 | 矩形，`>` 提示符，光标可见 |
| 代码块 | 等宽 + 语法高亮 |
| 状态栏 | 底部 24px，显示元信息 |
| 提示符 | `>` `$` `#` 前缀 |

---

## 反模式（不要这样做）

- ❌ 用比例字体（破坏对齐感）
- ❌ 圆角（破坏硬朗感）
- ❌ 大留白（终端风格的本质是密度）
- ❌ 加图标（字符界面用字符）
- ❌ 用于普通用户产品

---

## 平台适配提示

| 平台 | 注意事项 |
|---|---|
| 微信小程序 | **不适合**（小屏 + 微信气质） |
| iOS App | 仅开发者工具类 App |
| Android App | 同上 |
| 网站 | **最佳平台**，大屏才能承载密度 |

---

## 动效与动画

| 项目 | 规格 |
|---|---|
| 过渡曲线 | linear |
| 过渡时长 | 极快（50ms）——终端无缓冲 |
| hover 效果 | 反色（背景↔文字互换） |
| 页面切换 | 无动画——瞬间切换 |
| 加载动画 | 光标闪烁（`_` 或 `█` 块光标） |
| 特殊动效 | 文字逐字符打出（typewriter），状态色即时切换 |

**要点**：动效就是「无动效」——终端的本质是即时响应，不加装饰。
