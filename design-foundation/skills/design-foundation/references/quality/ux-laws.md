# UX 法则与可用性启发式

**用途**：做设计决策时的**判断依据**。不是装饰性知识，是评审时的具体抓手。

> 来源：`jpoindexter/dec-skills`（设计工程 canon）、Nielsen Norman Group、经典交互设计文献

---

## 一、Nielsen 十大可用性启发式

最容易被违反的五条（按频率排序）：

| # | 启发式 | 常见违反 |
|---|---|---|
| 1 | **系统状态可见** | 加载没反馈、操作没结果、不知道发生什么 |
| 2 | **贴近真实世界** | 用技术术语、图标含义模糊 |
| 3 | **用户控制与自由** | 没有撤销、没有返回、没有取消 |
| 4 | **一致性与标准** | 同一个操作在不同页面行为不同 |
| 5 | **防错** | 该禁用的没禁用、危险操作没有二次确认 |
| 6 | **识别优于回忆** | 让用户记信息（订单号、配置） |
| 7 | **灵活高效** | 老手没有快捷方式 |
| 8 | **美观简约** | 信息过载、重点不突出 |
| 9 | **帮助用户识别诊断错误** | 错误提示只说「出错了」 |
| 10 | **帮助文档** | 找不到帮助 |

**评审时怎么问**：
- 用户知道现在是什么状态吗？
- 用户能撤销吗？
- 这个操作和别处一样吗？
- 用户会误操作吗？
- 用户需要记住什么吗？

## 二、经典定律

### 费茨定律（Fitts's Law）
**目标越大、越近，越容易点。**

应用：
- 主要操作按钮要大
- 高频操作放在拇指热区（移动端下半屏）
- 相关操作靠近（减少移动距离）
- 危险操作**远离**常用操作

### 希克定律（Hick's Law）
**选项越多，决策越慢。**

应用：
- 导航项控制在 **5–9 个**（小程序 TabBar 最多 5 个）
- 表单分步，不要一次给 20 个字段
- 默认选项帮用户做决定
- 高级选项折叠

### 米勒定律（Miller's Law）
**工作记忆容量约 7±2 项。**

应用：
- 列表一次不超过 7 项
- 导航分组不超过 7 组
- 表单一屏不超过 7 个字段

### 格式塔原理（Gestalt）
**人眼会自动把相似/接近的元素归为一组。**

| 原理 | 应用 |
|---|---|
| **接近** | 相关的元素放近，不相关的放远 |
| **相似** | 同类型元素用同样式 |
| **连续** | 列表、时间线用连续视觉 |
| **闭合** | 卡片用边框/背景框定 |
| **共同区域** | 用背景色区分区块 |

### 雅各布定律（Jakob's Law）
**用户大部分时间花在别的网站上，所以他们希望你这里和别处一样。**

应用：
- 遵循平台惯例（小程序用小程序的，App 用 App 的）
- 不要为了创新而创新核心流程
- 例外：品牌差异点可以有，但**流程要符合预期**

### 峰终定律（Peak-End Rule）
**用户记住的是体验的峰值和结尾，不是整体平均。**

应用：
- 设计「高光时刻」（下单成功、完成任务的庆祝）
- 结尾体验要完整（不要在高潮处戛然而止）
- 错误体验的结尾要给出路

## 三、信息架构原则

| 原则 | 说明 |
|---|---|
| **多次点击原则** | 与其一次展示所有，不如让用户多点几次但每次都简单 |
| **分层展示** | 概览 → 详情，不要一上来就给全部 |
| **一致的分类** | 同一个东西只能在一个地方（不要重复入口） |
| **可扫读** | 标题、加粗、列表，不要大段文字 |
| **有路可退** | 任何页面都能返回、能退出 |

---

## 四、移动端特有

| 原则 | 说明 |
|---|---|
| **拇指热区** | 高频操作放屏幕下半部 |
| **减少输入** | 能用选择就不要打字（小程序可调用微信接口） |
| **防误触** | 手指点击精度低，控件间距要够 |
| **即时反馈** | 触摸后 100ms 内要有视觉反馈 |
| **尊重系统** | 不要覆盖系统手势（边缘返回、上滑） |

---

## 五、文案原则

- **说用户的语言**，不说技术术语
- **动词开头**：按钮用「立即购票」不用「提交」
- **具体**：用「已保存到我的订单」不用「操作成功」
- **错误要说怎么办**：不只说「出错了」，要说「网络异常，请重试」
- **简洁但不冷漠**：避免「非法输入」这种机器口吻

---

## 评审时怎么用

拿到一张设计稿，按这个顺序问：

1. **用户知道在哪、能去哪吗？**（导航/信息架构）
2. **状态可见吗？**（加载/空/错误/成功）
3. **能撤销、能退出吗？**
4. **会误操作吗？**（防错）
5. **符合平台惯例吗？**（雅各布定律）
6. **重点突出吗？**（美观简约）
7. **文案说人话吗？**
