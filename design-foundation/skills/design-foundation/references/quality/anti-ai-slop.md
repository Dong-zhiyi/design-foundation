# 反 AI 味清单

**「AI 味」不是玄学**，它有可识别的特征。`zhuyansen/awesome-claude-design-skills` 团队实测了 22 个页面（10 个 skill × 2 次 + 无 skill 对照），总结出「AI 脸」的具体特征。

> 来源：`zhuyansen/awesome-claude-design-skills` 端到端实测、`cumabozkurt/god-of-design` anti-slop gate、`joeseesun/qiaomu-design`
>
> ⚠️ **2026-10 更新**：默认 AI 脸已经变了。旧清单里的「紫渐变」不再常见，**新默认是 teal/cyan 强调色 + 米白底 + 衬线标题**。见下方「一·B」。

## 一、AI 味的典型特征

### 🎨 视觉层

| 特征 | 说明 | 怎么改 |
|---|---|---|
| **紫色渐变** | 蓝紫 `#667EEA → #764BA2` 是 AI 最爱的渐变 | 换成品牌色，或不用渐变 |
| **渐变文字** | 标题文字用渐变色 | 纯色文字 |
| **emoji 当图标** | 🐱📦🚀 代替真图标 | 用图标库 |
| **居中 Hero** | 大标题居中 + 副标题 + 一个大按钮 | 左对齐，或不对称构图 |
| **三个卡片并排** | 「功能一/功能二/功能三」等宽三卡 | 用 Bento Grid 打破对称 |
| **无理由的玻璃卡片** | 到处都是毛玻璃 | 只在有背景的地方用 |
| **圆角 + 阴影泛滥** | 所有元素都圆角 + 投影 | 有节制地使用 |
| **千篇一律的留白** | 每个区块上下都是 96px | 留白要有节奏变化 |

### 📐 布局层

| 特征 | 说明 | 怎么改 |
|---|---|---|
| **绝对对称** | 所有元素都居中对齐 | 引入不对称 |
| **栅格死板** | 永远 12 栏等宽 | 打破网格 |
| **层级扁平** | 所有元素同样大小 | 建立明确的主次 |
| **平均主义** | 每个功能都一样重要 | 有重点 |

### ✍️ 文案层

| 特征 | 说明 | 怎么改 |
|---|---|---|
| **空话连篇** | 「极致体验，畅享未来」 | 说具体的功能和好处 |
| **过度热情** | 「太棒了！」「当然可以！」 | 平实、专业 |
| **emoji 点缀** | 每句话后面跟 emoji | 去掉 |
| **三段式** | 任何回答都分三点 | 按内容组织 |
| **开头必吹** | 「这是一个非常好的问题」 | 直接回答 |

### 🧩 组件层

| 特征 | 说明 | 怎么改 |
|---|---|---|
| **按钮文字笼统** | 「了解更多」「立即体验」 | 说清会发生什么 |
| **卡片内容空** | 图标 + 标题 + 一句话 | 提供真实信息密度 |
| **图表默认样式** | 直接甩个柱状图 | 按数据特点选图表 |
| **状态缺失** | 只有默认态 | 补全所有状态 |

## 一·B、2026 实测指纹（更新版）

**2026-10 实测**：`zhuyansen/awesome-claude-design-skills` 跑 10 个 skill × 2 次同一落地页，结论：

- 旧的「紫渐变」已经不常见
- **新的默认脸 = teal/cyan 强调色 + 米白底 + 衬线标题**
- 10 个 skill 里 **2 个完全复现默认脸**，4 个复现 0–1 项

| 指纹 | 长什么样 | 怎么破 |
|---|---|---|
| **teal/cyan 强调色** | `#16d5e6` 附近的青绿出现在 CTA、标题强调、焦点环、图表 | 先定品牌色再生成 |
| **blinking status dot** | 导航右上角一个动画绿点，表示「live / AI」 | 明确说「不要动画状态点」 |
| **container soup** | pill 套 card 套 card，padding 24/24/24 堆叠 | 限制嵌套 ≤2 层 |
| **默认衬线标题** | Tiempos / Source Serif 类衬线 + 无衬线正文 | 指定字体栈（字重 + 字距），别只说「有设计感」 |
| **卡片左侧 accent bar** | 每张卡片左边一条 4px 彩条，无语义 | 彩条只留给一种角色（如严重程度） |
| **三列特性网格** | landing 第二段几乎必是三列等宽 | 明确「不要三列特性网格，用 marquee / 交错行 / 单列」 |
| **Lucide 默认图标** | 全线 Lucide，没换库 | 单一家族（Phosphor / Heroicons / 自定义），要么纯文字 |
| **生成式 hero 忽略 token** | 配图配色和 DESIGN.md 无关 | 约束「配图只用 `--bg` / `--accent` / `--text`」 |
| **圆角 + 阴影泛滥** | 所有元素都圆角 + 投影 | 有节制地使用 |
| **千篇一律的留白** | 每个区块上下都是 96px | 留白要有节奏变化 |

> 来源：`zhuyansen/awesome-claude-design-skills`（2026-10 实测）、`rohitg00/awesome-claude-design`（Claude Design 指纹清单）

**关键结论**：**只靠「别用紫渐变」挡不住 2026 年的 AI 味。** 指纹在变，清单要跟着实测更新。

## 二、为什么会这样

AI 倾向于：
1. **取平均值**——训练数据的均值就是「安全但平庸」
2. **过度礼貌**——被 RLHF 训出来的
3. **模式化**——见过最多的布局就是三卡片
4. **缺乏约束**——没有品牌、没有用户、没有场景时的默认输出

**解法**：**给足约束**（平台、风格、用户、场景、品牌），约束越具体，AI 越不容易掉回默认。

## 三、自查流程

拿到一张设计稿，问这 10 个问题：

1. 把 logo 遮住，能看出是什么产品吗？（还是任何产品都能套？）
2. 主色是品牌色还是「安全色」？
3. 有没有至少一处**不对称**？
4. 信息密度是否合适？（太空 = 没内容；太满 = 没重点）
5. 图标是真图标还是 emoji？
6. 有没有「三卡片并排」？
7. 文案是具体的还是空话？
8. 有没有明确的视觉焦点？
9. 状态齐全吗？（hover/loading/empty/error）
10. 换个人来做，会做出一样的吗？（如果会，说明太模式化）

## 四、具体改法

### 改法 1：打破对称
- 主操作靠左，辅助信息靠右
- 大图 + 小文字，或反之
- 用 Bento Grid 代替等宽卡片

### 改法 2：建立层级
- 一个页面**只有一个视觉焦点**
- 用大小、颜色、字重区分主次
- 次要信息**真的次要**（小、灰、折叠）

### 改法 3：注入品牌
- 品牌色占主导（不是点缀）
- 品牌字体（标题）
- 品牌特有的图形元素

### 改法 4：真实内容
- 用**真实文案**代替 Lorem ipsum
- 用**真实数据**代替「功能一/二/三」
- 考虑**空态和极端数据**（100 条数据时长什么样）

### 改法 5：加入约束
- 「首屏必须看到 X」
- 「这个页面要在 3 秒内传达 Y」
- 「用户是 50 岁的医生」

## 五、反模式对照表

| AI 味 | 有设计感 |
|---|---|
| 紫渐变背景 | 纯色或品牌渐变 |
| 居中对称 | 不对称平衡 |
| 三个等宽卡片 | Bento Grid / 大小对比 |
| emoji 图标 | 统一风格的线性图标 |
| 大段留白 | 有节奏的留白 |
| 全圆角 | 有节制地用圆角 |
|  everywhere 阴影 | 只在需要层级处用 |
| 空话文案 | 具体的功能描述 |

## 六、评审时的话术

不要说「感觉有点 AI 味」（太模糊），要说具体：

- ❌ 「这里有点 AI 」
- ✅ 「三个卡片等宽且居中，是典型的 AI 布局，改成 Bento Grid」
- ✅ 「这个紫渐变不是品牌色，换成 #8C1D18」
- ✅ 「按钮文案『立即体验』太笼统，改成『免费试听一节课』」
- ✅ 「没有空状态，用户第一次进来看到什么？」

## 检查清单

**旧指纹（2024）**：
- [ ] 主色是品牌色（不是紫渐变）
- [ ] 至少一处不对称
- [ ] 有明确视觉焦点
- [ ] 图标来自图标库（不是 emoji）
- [ ] 文案具体（不是空话）
- [ ] 没有「三卡片并排」
- [ ] 留白有节奏（不是处处 96px）
- [ ] 状态齐全
- [ ] 用了真实内容
- [ ] 遮住 logo 也能看出产品特性

**新指纹（2026）**：
- [ ] 强调色不是默认 teal/cyan
- [ ] 没有动画 status dot
- [ ] 容器嵌套 ≤2 层（不是 container soup）
- [ ] 标题字体是指定的，不是默认衬线
- [ ] 卡片没有无语义的左侧 accent bar
- [ ] landing 第二段不是三列特性网格
- [ ] 图标是单一家族，不是默认 Lucide
- [ ] 配图配色来自 token
- [ ] 遮住 logo 也能看出产品特性（**这条永远有效**）
- [ ] 换个人来做，不会做出一样的（**这条永远有效**）
