# 可访问性基线（WCAG 2.2 AA）

**这不是加分项，是底线。** 设计稿过不了这关，开发实现再好也没用。

> 来源：W3C WCAG 2.2、`plugin87/ux-ui-agent-skills`（WCAG 2.2 AA-AAA 门禁）

---

## 一、对比度（最关键）

| 文本类型 | AA 要求 | AAA 要求 |
|---|---|---|
| 正文（< 18pt） | **≥ 4.5:1** | ≥ 7:1 |
| 大字号（≥18pt 或 14pt Bold） | **≥ 3:1** | ≥ 4.5:1 |
| 图标、边框、控件边缘 | **≥ 3:1** | — |
| 纯装饰元素 | 无要求 | — |

**常见翻车**：
- 灰色辅助文字 `#999` on 白底 ≈ 2.8:1 ❌
- 浅灰占位符 ≈ 2:1 ❌
- 白色文字压在浅色图片上 ❌

**工具**：Stark、Contrast Checker、浏览器 DevTools

---

## 二、颜色不能是唯一信息载体

**规则**：不能只靠颜色区分状态，必须加**图标、文字或形状**。

❌ 错误：用红/绿圆点表示成功/失败
✅ 正确：✓ / ✕ 图标 + 颜色 + 文字

❌ 错误：用颜色区分图表数据系列
✅ 正确：不同形状或纹理 + 颜色

---

## 三、焦点与键盘

| 要求 | 说明 |
|---|---|
| **焦点可见** | 键盘焦点必须有明显视觉指示（不能去掉 `outline`） |
| **焦点顺序合理** | 按视觉顺序（从上到下，从左到右） |
| **无键盘陷阱** | 用户能进出所有交互元素 |
| **跳过导航** | 长页面提供「跳到主要内容」 |

---

## 四、触控目标

| 平台 | 最小尺寸 |
|---|---|
| **微信小程序** | 7–9mm 物理尺寸（约 44–50px @2x） |
| **iOS** | 44×44 pt |
| **Android** | 48×48 dp |
| **WCAG 2.2** | 24×24 CSS px（AA） |

**注意**：视觉尺寸可以小，但**热区要够**（用透明 padding 扩大）。

---

## 五、文字

| 要求 | 说明 |
|---|---|
| **最小字号** | 正文 ≥14px；辅助 ≥12px |
| **行高** | 中文 ≥1.7；英文 ≥1.5 |
| **行宽** | 45–75 字符（中文 25–40 字） |
| **字间距** | 不要为 0 或负值（影响可读） |
| **可缩放** | 支持系统字号缩放（iOS Dynamic Type / Android sp） |

---

## 六、动效与癫痫

| 要求 | 说明 |
|---|---|
| **不闪频** | 避免 >3 次/秒的闪烁（可能诱发癫痫） |
| **尊重减少动效** | 必须支持 `prefers-reduced-motion: reduce` |
| **不自动播放** | 视频/动画不自动播放（或可暂停） |
| **可暂停** | 轮播、动画必须能暂停 |

**降级方案**：`prefers-reduced-motion` 时，把位移/缩放动画替换为**淡入淡出**。

---

## 七、表单

| 要求 | 说明 |
|---|---|
| **标签可见** | 不能用占位符代替 label（输入后消失） |
| **错误明确指出** | 说明哪个字段错了、怎么改 |
| **错误不用颜色唯一表达** | 加图标和文字 |
| **必填标识** | 明确标出哪些是必填 |
| **分组相关字段** | 用 fieldset / legend |

---

## 八、图片与媒体

| 要求 | 说明 |
|---|---|
| **替代文本** | 信息性图片必须有 alt |
| **装饰图片** | alt 置空（不要写「图片」） |
| **信息图** | 提供文字版 |
| **视频** | 提供字幕 |

---

## 九、深色模式

- 不能简单反色（纯黑变纯白会刺眼）
- 用**语义化颜色**，让系统自动切换
- 深色下**对比度要求不变**
- 阴影在深色下几乎不可见 → 改用描边或色差分层

---

## 十、设计稿自检（每次交付前过一遍）

- [ ] 所有正文对比度 ≥4.5:1（实测，不是目测）
- [ ] 所有大字号/图标对比度 ≥3:1
- [ ] 状态不只靠颜色区分（有图标/文字）
- [ ] 焦点态设计好了（不是靠浏览器默认）
- [ ] 触控目标达平台标准
- [ ] 最小字号 ≥12px
- [ ] 行高中文 ≥1.7
- [ ] 动效有 `prefers-reduced-motion` 降级
- [ ] 表单有错误态和标签
- [ ] 图片有 alt 策略
- [ ] 深色模式已适配且对比度达标

## 快速对比度速查

| 前景 | 背景 | 对比度 | 结论 |
|---|---|---|---|
| `#000000` | `#FFFFFF` | 21:1 | ✅ |
| `#1A1A1A` | `#FFFFFF` | 18:1 | ✅ |
| `#6B6B6B` | `#FFFFFF` | 4.9:1 | ✅ AA |
| `#8A8A8A` | `#FFFFFF` | 3.5:1 | ❌ 仅大字号 |
| `#999999` | `#FFFFFF` | 2.8:1 | ❌ |
| `#FFFFFF` | `#8C1D18` | 6.3:1 | ✅ |
| `#FFFFFF` | `#A6A6A6` | 2.3:1 | ❌ |
