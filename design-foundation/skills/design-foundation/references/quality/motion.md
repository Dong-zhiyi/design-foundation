# 动效规范

**动效不是装饰，是**：表达层级关系、反馈操作结果、引导注意力。

> 来源：`joepUI/motion-ref-skill`（111 个生产动效）、Material 3 motion、Apple HIG motion

---

## 一、什么时候用动效

| ✅ 该用 | ❌ 不该用 |
|---|---|
| 反馈操作结果（按下、成功、失败） | 纯装饰的循环动画 |
| 表达层级转场（进入/退出） | 拖慢用户完成任务的动画 |
| 引导注意力（新消息、提示） | 无意义的弹跳、闪烁 |
| 表达状态变化（展开/收起） | 大面积位移 |
| 品牌表达（谨慎） | 影响可读性的动效 |

**判断标准**：如果动效删掉，用户会损失信息吗？不会 → 大概率是多余的。

---

## 二、时长档

| 档位 | 时长 | 适用 |
|---|---|---|
| **即时** | 100ms | 悬停反馈、按下态 |
| **快** | 150ms | 小元素变化、tooltip |
| **标准** | 250ms | 展开/收起、卡片 |
| **慢** | 400ms | 大区域转场、模态框 |
| **超时** | >500ms | ⚠️ 用户会察觉卡顿，慎用 |

**原则**：
- **元素越小，动效越快**（按钮 150ms，模态框 400ms）
- **位移距离越远，时长越长**
- **进入快，退出更快**（进入 250ms，退出 200ms）

## 三、缓动曲线

| 曲线 | 感觉 | 适用 |
|---|---|---|
| **Standard** `cubic-bezier(0.2,0,0,1)` | 平滑、中性 | 大多数情况（Material 3） |
| **Decelerate** `cubic-bezier(0,0,0.2,1)` | 快进慢出 | 元素**进入** |
| **Accelerate** `cubic-bezier(0.3,0,1,1)` | 慢进快出 | 元素**退出** |
| **Emphasized** | 有弹性 | 强调、品牌 |
| **Linear** | 机械 | 进度条、旋转 |

**要点**：
- 进入用 Decelerate，退出用 Accelerate（符合物理直觉）
- **不要用 ease-in-out 做位移**（会显得拖沓）
- 避免 `bounce` / `elastic`（除非是刻意的设计语言）

## 四、常见动效规范

### 4.1 微交互（100–200ms）
- 按钮按下：缩放 0.97 + 颜色变化
- 开关切换：滑块位移 + 轨道变色
- 收藏：图标填充 + 轻微弹跳（150ms）

### 4.2 展开/收起（250–300ms）
- 高度变化 + Standard 曲线
- 箭头旋转 180°

### 4.3 转场（300–400ms）
- **层级转场**：新页面从右侧滑入（push），返回时向左滑出
- **模态框**：从底部滑入（sheet）或居中缩放（dialog）
- **共享元素**：图片/卡片放大过渡

### 4.4 加载
- **骨架屏**优于转圈（内容可预期）
- 进度条用于明确进度的任务
- 局部加载优于全局加载

### 4.5 滚动
- 列表滚动**不要加视差**（晕动 + 性能）
- 吸顶元素用阴影/描边表达层级

## 五、平台差异

| 平台 | 动效特点 |
|---|---|
| **iOS** | 偏好流畅的层级转场、毛玻璃、弹簧曲线 |
| **Android** | Material 3 的容器变换、Standard 曲线 |
| **微信小程序** | 性能受限，避免大面积动画；用 CSS transition |
| **网站** | 自由度高，但注意性能（用 transform/opacity） |

---

## 六、性能

**只用 GPU 友好属性**：
- ✅ `transform: translate/scale/rotate`
- ✅ `opacity`
- ❌ `width` / `height` / `top` / `left`（触发重排）

**其他**：
- 用 `will-change` 提前告知（但别滥用）
- 动画元素加 `transform: translateZ(0)` 提升为图层
- 避免同时动画多个大面积元素

---

## 七、无障碍（重要）

**必须支持 `prefers-reduced-motion`**：

```css
@media (prefers-reduced-motion: reduce) {
  * {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}
```

**降级方案**：
- 位移/缩放 → **淡入淡出**
- 视差 → **关闭**
- 自动播放 → **关闭**

**禁止**：
- 闪烁 >3 次/秒
- 大面积高频动画

---

## 八、设计稿怎么标动效

在标注里写清三项：

```
元素：卡片展开
时长：250ms
缓动：cubic-bezier(0.2, 0, 0, 1)
```

**进阶**：用 Figma 的 Smart Animate 或 Prototype 做可交互原型，比文字描述准确。

## 检查清单

- [ ] 每个动效都有明确目的（不是装饰）
- [ ] 时长在 100–400ms 档内
- [ ] 进入/退出用了合适的缓动
- [ ] 只用 transform/opacity
- [ ] 有 `prefers-reduced-motion` 降级
- [ ] 没有闪烁 >3 次/秒
- [ ] 加载态用骨架屏而非转圈
- [ ] 标注里写清时长 + 缓动
