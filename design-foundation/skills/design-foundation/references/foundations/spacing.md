# 间距系统速查

**4px 基准的完整间距体系。** 所有间距都是 4 的倍数，AI 生成时直接查表。

> 来源：`figma/sds`（Simple Design System 间距）、`zeke/swiss-design-skill`（Swiss 间距规则）、`luogao/design-atlas`（tokens.css 间距系统）

---

## 一、4px 基准间距阶

| 档位 | 数值 | 用途 |
|---|---|---|
| 1 | 4px | 图标内边距、文字与图标间距 |
| 2 | 8px | 紧凑列表项间距、标签内边距 |
| 3 | 12px | 卡片之间间距、表单字段间距 |
| 4 | 16px | 卡片内边距、区块之间间距 |
| 5 | 20px | 中等间距（较少用） |
| 6 | 24px | 大区块间距、弹窗内边距 |
| 7 | 32px | 页面级间距、大卡片内边距 |
| 8 | 40px | 超大间距（Hero 区域内部） |
| 9 | 48px | 页面区块间距（桌面） |
| 10 | 64px | 落地页区域间距（移动） |
| 11 | 80px | 落地页区域间距（桌面） |
| 12 | 96px | 超大留白（日系/编辑风格） |

**记忆口诀**：4-8-12-16-24-32-48-64-96（常用档）

## 二、场景速查

### 组件内部

| 元素 | 间距 |
|---|---|
| 图标与文字 | 4–8px |
| 按钮内边距（水平） | 12–16px |
| 按钮内边距（垂直） | 8–12px |
| 输入框内边距 | 12–16px |
| 标签内边距 | 4–8px |
| 头像与文字 | 8–12px |

### 组件之间

| 元素 | 间距 |
|---|---|
| 表单字段之间 | 16–24px |
| 列表项之间 | 0（分隔线）或 8–12px |
| 卡片之间 | 12–16px |
| 按钮组之间 | 8–12px |
| Tab 之间 | 16–24px |

### 区块之间

| 元素 | 间距 |
|---|---|
| 导航与内容 | 16–24px |
| 标题与内容 | 16–24px |
| 内容区块之间 | 24–32px |
| 页面级大区块 | 48–64px |
| 落地页区域之间 | 80–120px（桌面）/ 48–64px（移动） |

### 页面边距

| 平台 | 边距 |
|---|---|
| 移动端 | 16px |
| 平板 | 24px |
| 桌面 | 32–48px |
| 最大内容宽度 | 1200px（居中） |

| 风格 | 偏好 | 常用档位 | 说明 |
|---|---|---|---|
| 经典剧院 | 宽松 | 16/24/32/48 | 留白营造仪式感 |
| 现代深色 | 紧凑 | 4/8/12/16/24 | 信息密度高 |

## 四、响应式间距缩放

**原则**：移动端间距缩小，桌面端间距放大。

| 场景 | 移动（S） | 平板（M） | 桌面（L/XL） |
|---|---|---|---|
| 页面边距 | 16px | 24px | 32–48px |
| 卡片之间 | 8–12px | 12–16px | 16–24px |
| 区块之间 | 24–32px | 32–48px | 48–64px |
| 落地页区域 | 48–64px | 64–80px | 80–120px |

**不要线性缩放**：不是所有间距都乘以 1.5，而是根据场景选择合适档位。

## 五、常见错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 用 3px/5px/7px | 破坏 4px 基准，视觉不统一 | 只用 4 的倍数 |
| 所有间距都用 16px | 没有层级感 | 根据场景选不同档位 |
| 移动端间距过大 | 一屏显示内容太少 | 移动端用紧凑档位 |
| 桌面端间距过小 | 大屏幕上显得拥挤 | 桌面端用宽松档位 |
| 忽略页面边距 | 内容贴边，不美观 | 移动端至少 16px 边距 |

## 六、检查清单

- [ ] 所有间距都是 4 的倍数
- [ ] 组件内部间距合理（图标 4-8px，按钮 12-16px）
- [ ] 组件之间间距合理（卡片 12-16px，字段 16-24px）
- [ ] 区块之间间距合理（24-32px）
- [ ] 页面边距合理（移动 16px，桌面 32-48px）
- [ ] 响应式间距有缩放（移动紧凑，桌面宽松）
- [ ] 风格间距偏好一致（日系宽松，终端紧凑）
