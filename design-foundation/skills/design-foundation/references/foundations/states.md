# 状态设计参考

**4 种通用状态在 16 种风格下的表现规则。** 空状态/加载/错误/成功的视觉语言必须和风格一致。

> 来源：`MKAbuMattar/uidesign`（无障碍状态）、`tongsalangsingha/AI-prototyper-tool`（状态组件）、`figma/sds`（状态变体）

---

## 一、4 种通用状态

| 状态 | 触发场景 | 核心目标 |
|---|---|---|
| **Empty** | 无数据、首次使用、搜索无结果 | 引导用户行动 |
| **Loading** | 数据请求中、页面切换 | 告知进度，减少焦虑 |
| **Error** | 请求失败、表单校验失败、无网络 | 说明问题 + 提供解决方案 |
| **Success** | 提交成功、操作完成 | 确认结果 + 引导下一步 |

## 三、通用规则

### 插画尺寸

| 场景 | 尺寸 |
|---|---|
| 移动端空状态 | 120–160px |
| 桌面端空状态 | 160–240px |
| 行内状态图标 | 24–32px |
| Toast/Snackbar 图标 | 20–24px |

### 文案规则

- **Empty**：说明状态 + 引导行动（「还没有内容，来创建第一个吧」）
- **Loading**：尽量无文案，或用「加载中…」
- **Error**：说明问题 + 解决方案（「网络断开，请检查连接后重试」）
- **Success**：确认结果 + 下一步（「保存成功」，不需要「下一步」）

### 动画规则

- **Empty**：无动画或极轻淡入
- **Loading**：必须有动画（旋转/脉动/骨架屏）
- **Error**：可加轻微抖动（shake）引起注意
- **Success**：可加勾选动画（draw checkmark）

## 四、压力测试场景（扩展）

4 种通用状态之外，组件在实际使用中还会遇到以下场景。简报阶段就应考虑这些场景，不要等开发时才暴露。

### 数据量维度

| 场景 | 说明 | 设计关注点 |
|---|---|---|
| **零项** | 列表/表格无任何数据 | 空状态插画 + 引导行动按钮 |
| **单项** | 只有一条数据 | 布局是否仍然合理（不要显得太空） |
| **典型量** | 正常使用的数据量（如 5-10 条） | 标准布局 |
| **大量（需滚动）** | 超出首屏，需要滚动或分页 | 滚动性能、sticky header、分页控件 |
| **极大量（需搜索/过滤）** | 数据多到需要搜索才能找到 | 搜索框、过滤器、排序控件 |

### 内容长度维度

| 场景 | 说明 | 设计关注点 |
|---|---|---|
| **空文本** | 字段值为空字符串 | 显示占位符还是隐藏该字段？ |
| **短文本** | 1-2 个字（如「是」「否」） | 容器是否显得过宽 |
| **典型长度** | 正常标题/描述长度 | 标准布局 |
| **超长文本** | 60+ 字符不可断行 | 截断策略（`…` + tooltip / 展开 / 多行） |
| **多行文本** | 含换行符的长文本 | 行高、段间距、最大行数限制 |

### 状态维度（扩展）

| 场景 | 说明 | 设计关注点 |
|---|---|---|
| **Disabled** | 控件不可用 | 视觉降级 + 不可点击光标 + 可选 tooltip 说明原因 |
| **Read-only** | 可查看不可编辑 | 与 disabled 的视觉区分 |
| **Pending** | 操作已提交但未确认 | 与 Loading 区分（Loading=等待数据，Pending=等待确认） |
| **Partial** | 部分成功/部分失败 | 批量操作中的混合状态 |
| **Stale** | 数据过期/正在刷新 | 显示旧数据 + 刷新指示器 |

### 环境维度

| 场景 | 说明 | 设计关注点 |
|---|---|---|
| **窄容器** | 320px 宽度 | 不裁切、不重叠、操作可达 |
| **宽容器** | 1440px+ 宽度 | 不拉伸变形、合理最大宽度 |
| **深色模式** | 暗色主题 | 色彩映射正确、阴影改用描边 |
| **高对比度模式** | 系统强制高对比 | 不依赖颜色/阴影传达信息 |
| **200% 缩放** | 浏览器放大 | 布局不破裂、文字不溢出 |

### 国际化维度

| 场景 | 说明 | 设计关注点 |
|---|---|---|
| **长文本语言** | 德语/俄语等（比英文长 30-50%） | 容器用 `max-width` + `min-height`，不用固定宽高 |
| **RTL 语言** | 阿拉伯语/希伯来语 | 逻辑属性（`margin-inline-start`），图标镜像 |
| **CJK 混排** | 中英文混排 | 行高、字间距、基线对齐 |
