# 知识库总览

这是 `design-foundation` 技能的知识库。**每条知识都标了来源**，可以追溯。

## 设计理念

1. **平台 + 技术栈优先** —— 先定平台和技术栈，再谈风格
2. **数值优先** —— 说「圆角 12px」，不说「圆润感」
3. **状态优先** —— 没有状态的设计是不完整的
4. **门禁优先** —— 不过门禁的稿子不往外发
5. **先验证再动手** —— MCP 没通、文件不对，不要开始画
6. **可追溯** —— 宁可少收录，不要没来源的内容

## 知识条目格式

### 风格卡片
```
名称 / 调性 / 适用场景 / 不适用 / 来源
色板 / 字体 / 形状与质感 / 布局规则 / 组件要点 / 反模式 / 平台适配
```

### 平台规范
```
画板基准 / 单位 / 顶部结构 / 底部结构 / 字体 / 色彩 / 素材尺寸 / 交互热区 / 特殊约束 / 检查清单
```

### 架构
```
分层结构 / 每层定义 / 什么时候用 / 什么时候不用 / Figma 组织 / 反模式 / 检查清单
```

## 快速检索

**想找平台尺寸？** → `platforms/_index.md` 的对照表

**想查技术栈基准？** → `tech-stacks/_index.md` 的对照表（uni-app x 390 / 经典 uni-app 750 / H5 375 / 原生 iOS 390…）

**想选风格？** → `styles/_index.md` 按场景速查

**想定架构？** → `architectures/_index.md` 的决策树

**想选字体？** → `libraries/fonts.md` 速查表

**想选图标？** → `libraries/icons.md` 速查表 + `libraries/icons/` 各库详档

**想过门禁？** → `quality/review-gate.md`

**想画 Figma？** → `figma-delivery/naming.md`

**想查通用组件？** → `figma-delivery/component-catalog.md`（先查目录，再查文件内组件）

**第一次走全流程** → `examples/walkthrough.md`（通用，任何产品都能套用）
**想看具体案例** → `examples/case-theater-ticketing.md`（剧院售票，含完整决策过程）
