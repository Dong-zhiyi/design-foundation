# 微信小程序

> 来源：微信开放文档《小程序设计指南》+ `Billzhouheart/wechat-miniprogram-designUI`（GitHub，含官方规范整理与审核红线）

---

## 一、设计稿基准

| 项目 | 数值 | 说明 |
|---|---|---|
| **基准宽度** | **375px**（固定布局）或 **390px**（响应式布局） | 官方推荐 375；响应式用 390 |
| **单位** | rpx（responsive pixel） | **750rpx = 屏幕宽度**；设计稿按 750 交付时 1px = 1rpx |
| **倍图** | 常规 2x 切图；图标建议 3x | |

> ⚠️ 交付时务必写清楚：**「375 基准，750 交付」还是「390 基准」**。这是小程序还原出错的头号原因。

## 二、顶部结构（重点：胶囊按钮）

### 2.1 胶囊按钮（⚠️ 必避让）

微信在**所有页面右上角**放置官方胶囊控件，**开发者不可自定义内容**，只能选深色/浅色两套配色。

| 项目 | iOS | Android |
|---|---|---|
| 胶囊高度 | **32pt** | **32pt** |
| 胶囊宽度 | **88px** | **96px** |
| 状态栏到胶囊间距 | **4px** | **8px** |
| 胶囊距屏幕右边距 | 10px | 10px |

**设计规则**：
- 胶囊区域**不能放任何可交互元素**
- 胶囊下方和左侧要留出安全距离，避免点击冲突
- 自定义导航栏时（`navigationStyle: custom`），页面只有胶囊，其余都要自己画

### 2.2 导航栏

| 项目 | 数值 |
|---|---|
| 导航栏高度 | **128rpx**（不含状态栏） |
| 导航栏可自定义尺寸吗 | ❌ 不可，只能改颜色 |
| 自定义导航栏高度公式 | `胶囊高度(32) + 上下间距×2 + 状态栏高度` |
| 状态栏高度 | 由系统给出（`wx.getSystemInfoSync().statusBarHeight`），iPhone X 类 44px，老机型 20px |

**自定义导航栏示例**：
```
gap = 胶囊.top - 状态栏高度
导航栏高度 = 2 × gap + 32
```

### 2.3 状态栏

- 高度由系统决定，**不要写死**
- 颜色只能选 `black` / `white`（`navigationBarTextStyle`）

## 三、底部结构（TabBar）

| 项目 | 数值 |
|---|---|
| TabBar 高度 | **98rpx** |
| Tab 数量 | **最少 2 个，最多 5 个**（建议 ≤4） |
| Tab 图标 | **81×81px**（≤40kb，不支持网络图片） |
| 原生 TabBar | **仅供首页使用** |
| 自定义 TabBar | 需 `tabBar.custom: true` + 自定义组件 |

> ⚠️ 一个页面**不应出现两组以上**的标签分页栏。

---

## 四、字体

常用字号（pt）：**22 / 17 / 15 / 14 / 12**

| 用途 | 字号 |
|---|---|
| 导航标题 | 17pt |
| 正文主要内容 | 17pt / 15pt |
| 次要内容 | 14pt |
| 辅助说明 / 时间戳 | 12pt |
| 大标题 | 22pt |

字体使用**系统默认**（iOS: PingFang SC；Android: Roboto / 系统默认），不要自定义字体（除非品牌必须，且要考虑包体积）。

---

## 五、色彩

- 品牌绿：`#07C160`（微信默认，可改）
- 文字：主内容黑、次要灰、时间戳浅灰
- 链接蓝、完成绿、出错红
- 按下态：文字透明度降至 60%；不可点：30%
- **支持深色模式**：需配置 `darkmode: true` + `theme.json`

## 六、常用素材尺寸

| 素材 | 尺寸 |
|---|---|
| 头像 | **144×144px** |
| TabBar 图标 | 81×81px |
| 轮播图 | **16:9** |
| 分享图 | **5:4** |
| 胶囊按钮 | 高 32pt（iOS 88 宽 / Android 96 宽） |

## 七、交互与热区

- **点击热区**：物理尺寸 **7–9mm**（约等于 44–50px @2x）
- 手指点击精度低，控件不能太密
- 次级页面**左上角必须有返回**
- iOS 支持边缘右滑返回；Android 用物理返回键
- 页面栈深度**上限 10 层**，超了要改信息架构

---

## 八、加载与反馈

- 下拉刷新、启动页由微信提供，**不能自定义**（启动页只能放 Logo）
- 局部加载优于全局加载
- 同一页面**不要同时出现多个加载动画**
- 结果反馈：图标型 Toast（1.5s 自动消失，**不适用于错误提示**）、文字型 Toast、模态对话框、结果页

---

## 九、审核红线（12 项自查）

1. TabBar 数量必须在 2–5 之间
2. 胶囊区域不得放置可交互元素
3. 不得仿系统 UI（冒充微信官方控件）
4. 启动页不得放微信提供的加载指示以外的内容
5. 隐私授权流程必须完整
6. 不得诱导分享 / 关注
7. 支付流程需符合规范
8. 内容不能有违法违规信息
9. 深色模式下文字必须可读
10. 图片不得有版权问题
11. 不得频繁打扰用户（通知/弹窗）
12. 表单出错必须明确指出出错项
