# 网站 / Web App

> 与移动端的关键差异：**有 hover、无安全区、内容要约束最大宽度、导航可折叠**。

---

## 一、画板基准

### ⚠️ 先分清：你要做哪个？

| 场景 | 基准宽度 | 说明 |
|---|---|---|
| **移动端 H5**（手机浏览器 / 微信内嵌 / App WebView） | **375px** | ← **H5 的基准也是 375px** |
| 移动端 H5（2x 交付） | 750px | 部分团队按 2x 出稿 |
| **PC 网站 / 管理后台** | **1440px** | 完全不同的场景 |

> ⚠️ **最常见错误**：把移动端 H5 当成 PC 网站，用 1440 基准设计 → 手机上字太小、布局挤。
> **移动端 H5 的设计基准是 375px**，用 rem/vw 适配到大屏。

详见 [`../tech-stacks/h5.md`](../tech-stacks/h5.md)。

### PC 端断点

| 断点 | 宽度 | 典型设备 |
|---|---|---|
| sm | ≥ 640px | 大手机横屏 / 小平板 |
| md | ≥ 768px | 平板竖屏 |
| lg | ≥ 1024px | 笔记本 |
| xl | ≥ 1280px | 桌面 |
| 2xl | ≥ 1536px | 大屏 |

**PC 端设计稿基准**：
- **1440px**（主流）或 1280px
- 内容最大宽度：**1200–1280px**（居中，两侧留白）
- 响应式：移动优先，逐级增强

---

## 二、栅格系统

| 项目 | 常用值 |
|---|---|
| 栅格列数 | **12 栏**（或 24 栏） |
| 栏间距（Gutter） | 24px（桌面）/ 16px（移动） |
| 外边距（Margin） | 24–48px（桌面）/ 16–24px（移动） |
| 内容最大宽 | 1200–1280px |
| 基线网格 | 8px |

**为什么用 12 栏**：能被 2、3、4、6 整除，布局组合最灵活。

---

## 三、导航

| 场景 | 形态 |
|---|---|
| 板块 ≤ 7 | 顶部水平导航 |
| 板块 > 7 | 汉堡菜单 / 侧边栏 |
| 后台管理 | 左侧固定侧边栏（240–260px） |
| 移动端 | 底部 Tab 或汉堡菜单 |

**注意**：桌面端导航**不能直接照搬到移动端**，要折叠。

---

## 四、字体

- 正文字号：**16px**（最小 14px）
- 行高：1.5–1.75（正文）
- 标题层级：h1 32–48px / h2 24–32px / h3 20–24px / h4 18–20px
- 字体族：系统字体栈或 Web Font（注意加载性能）
- **中文行高要更大**（1.7–1.9），否则拥挤

---

## 五、色彩

- 支持**深色模式**（`prefers-color-scheme`）
- 用语义化 token，不要写死 hex
- 正文与背景对比度 ≥ 4.5:1（WCAG AA）
- 品牌色 + 中性灰阶 + 功能色（成功/警告/错误/信息）

---

## 六、交互态（移动端没有的）

| 状态 | 说明 |
|---|---|
| **hover** | 鼠标悬停反馈（按钮变色、链接下划线、卡片浮起） |
| **focus** | 键盘焦点环（**不能去掉**，无障碍必须） |
| **active** | 按下瞬间 |
| **disabled** | 禁用态（降低透明度或灰化） |
| **loading** | 加载态（骨架屏优于转圈） |
| **empty** | 空态（引导用户下一步） |
| **error** | 错误态（说明原因 + 解决方法） |

**移动端没有 hover**，所以移动端设计不要依赖 hover 传递关键信息。

---

## 七、悬停与指针

- **指针类型**：鼠标（fine pointer）vs 触摸（coarse pointer）
- 触摸设备**没有 hover**，控件要更大
- 用 `@media (hover: hover)` 判断是否有 hover 能力
- 用 `@media (pointer: coarse)` 判断是否触摸设备

---

## 八、响应式策略

**移动优先**：先设计最小屏，再用 `min-width` 逐级增强。

| 断点 | 布局变化 |
|---|---|
| < 640 | 单列，底部导航，字号偏小 |
| 640–768 | 单列变双列 |
| 768–1024 | 侧边栏出现，栅格变 8 栏 |
| 1024–1280 | 12 栏，内容最大宽生效 |
| > 1280 | 内容居中，两侧留白加大 |

**不要做**：把移动端布局等比放大到桌面。

---

## 九、性能与加载

- 首屏内容优先（骨架屏 > 转圈）
- 图片懒加载 + 响应式尺寸（`srcset`）
- 字体用 `font-display: swap`，避免 FOIT
- 动画用 `transform` / `opacity`（GPU 友好），少用 `width`/`height`/`top`/`left`

---

## 十、设计交付检查

- [ ] 画板 1440px，内容最大宽 1200–1280px
- [ ] 12 栏栅格，gutter 24px
- [ ] 所有交互态齐全（hover/focus/active/disabled/loading/empty/error）
- [ ] 深色模式已适配
- [ ] 响应式断点已设计（不是等比缩放）
- [ ] 中文行高 1.7–1.9
- [ ] 正文对比度 ≥4.5:1
- [ ] 图片与字体加载策略已考虑
