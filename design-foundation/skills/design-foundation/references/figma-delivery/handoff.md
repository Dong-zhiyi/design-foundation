# 设计交付清单

**交付不是「把 Figma 链接发出去」**，是让开发能准确还原。

---

## 一、交付物清单

| 交付物 | 内容 | 必需 |
|---|---|---|
| **设计稿** | Figma 文件链接 | ✅ |
| **设计规范简报** | `docs/design-brief.md` | ✅ |
| **令牌文件** | DTCG JSON / CSS 变量 | ✅ |
| **组件库** | 可复用的 Figma 组件 | ✅ |
| **标注** | 尺寸、间距、颜色、字体 | ✅ |
| **切图** | 图标、插画、特殊图形 | 视情况 |
| **动效说明** | 时长、缓动、触发条件 | 有动效时 |
| **状态说明** | 空态、加载、错误、极端数据 | ✅ |
| **交互说明** | 跳转、反馈、异常处理 | ✅ |

---

## 二、标注规范

### 标什么
- 尺寸（宽高、字号、行高）
- 间距（内外边距、元素间距）
- 颜色（hex + 变量名）
- 字体（family / size / weight / line-height / letter-spacing）
- 圆角、阴影
- 交互（hover / active / disabled 的差异）

### 怎么标
- **优先用 Figma 的 Dev Mode**（开发自己量）
- 关键数值写标注（不要指望开发每个都量）
- 用**注释（Annotation）**说明业务逻辑和异常情况

### 标注示例
```
按钮
├─ 高度：48px
├─ 圆角：24px（radius/full）
├─ 背景：color/brand/primary
├─ 文字：14px / 500 / #FFFFFF
└─ 状态：hover 时背景加深 10%
```

## 三、切图规范

| 类型 | 格式 | 倍图 |
|---|---|---|
| 图标 | SVG | 1x（矢量） |
| 位图（照片/插画） | PNG / WebP | 1x / 2x / 3x |
| 启动图 | PNG | 按机型 |
| Lottie 动画 | JSON | — |

**要点**：
- 图标**一律 SVG**（不要切 PNG）
- 位图用 WebP（体积更小）
- 命名：`<功能>/<名称>@2x.webp`

---

## 四、状态交付

**每个页面必须交付**：

| 状态 | 说明 |
|---|---|
| **默认态** | 正常显示 |
| **加载态** | 骨架屏 / loading |
| **空态** | 无数据时显示什么 |
| **错误态** | 网络失败、加载失败 |
| **极限态** | 超长文字、大量数据、图片加载失败 |
| **首次使用** | 新用户看到什么（引导） |

**不要只给一个「完美状态」的稿子。**

---

## 五、交互说明

写清楚：

| 项目 | 说明 |
|---|---|
| 跳转关系 | 从哪来到哪去 |
| 转场方式 | push / present / 无动画 |
| 反馈 | 点击后发生什么 |
| 异常处理 | 失败怎么办、能不能重试 |
| 手势 | 下拉刷新、左滑删除等 |

**建议**：用 Figma Prototype 做可交互原型，比文字清楚。

---

## 六、开发对接建议

1. **开工前对齐**：和开发过一遍设计稿，确认技术可行性
2. **走查节点**：开发完成 50% 时走查一次，不要等全部完成
3. **问题记录**：用 Figma 评论或文档记录问题，不要口头说
4. **验收标准**：提前说好「什么样算还原到位」
