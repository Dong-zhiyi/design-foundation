# 参考提取（第 4.5 步）

**把「形容词」转成「数值」。** 选定风格后，从真实参考里提取色板 / 字阶 / 圆角 / 间距 / 密度，写进简报。

> 来源：`tathagat22/plumb-mcp`（`plumb_brand`：实时截图参考站 → 读计算 CSS → 合成品牌板）、`mbeato/anti-slop-design`（本地真实应用 corpus + 检索）、`NN/g`（精确视觉关键词 + 轻量参考图）

---

## 为什么

风格卡片给的是**形容词**（「庄重有仪式感」「克制精确」），生成时需要的是**数值**（主色 `#8C1D18`、字阶 12/14/16/20、圆角 12px）。

技能原则写着「数值优先于形容词」——这一步就是把形容词转成数值。

---

## 什么时候做

- **推荐**：用户给了参考（网址 / 截图 / 竞品）
- **可选**：用户没给参考，但想要更准的品牌感
- **不做**：用户说「就按风格卡来，别折腾」

---

## 流程

### 第 1 步：收集参考

问用户要 **1–3 个**：
- 网址（竞品 / 喜欢的站）
- 截图（现有产品 / moodboard）
- 现成 Figma 文件

> ⚠️ **不要超过 3 个**。参考太多会互相打架。

### 第 2 步：提取

**网址**：
- 用 `browser-use` skill 打开 + 截图
- 读计算样式：主色、辅色、背景、文字色、字号、字重、圆角、间距
- 注意：读的是**数值**，不是感觉

**截图**：
- 直接读图
- 提取：主色 / 辅色 / 字体感觉 / 圆角大小 / 信息密度 / 情绪关键词

**Figma 文件**：
- 用 `framelink-mcp` 的 `get_figma_data` 读
- 用 `figwright-mcp` 的 `token_map` 直接映射变量

### 第 3 步：产出「品牌提取板」

写进《设计规范简报》，**带数值**：

```
品牌提取（来自：https://example.com）
├─ 主色    #8C1D18（深红，占主导）
├─ 辅色    #C9A227（金，点缀）
├─ 背景    #FAF7F2（暖白）
├─ 文字    #1A1A1A（主）/ #6B6B6B（次）
├─ 字阶    12 / 14 / 16 / 20 / 28
├─ 字重    400 / 500 / 700
├─ 圆角    4 / 8 / 12
├─ 间距    4 / 8 / 12 / 16 / 24 / 32
├─ 密度    中等偏松（卡片间距 24）
└─ 情绪    庄重、有仪式感、不花哨
```

### 第 4 步：写进简报

把提取板的数值**覆盖**风格卡的默认值。简报里注明来源：

```
色板来自参考 https://example.com（提取时间 2026-11-10）
```

---

## 没给参考怎么办

用风格卡的默认数值，并**明确告诉用户**：

```
你没给参考，我用的是「经典剧院」风格卡的默认色板。
如果想更贴合品牌，给我 1–3 个参考网址/截图，我重新提取。
```

**不要假装提取过。**

---

## 参考不是抄

**提取的是「数值和规律」，不是「照抄布局」。**

- ✅ 学它的色板、字阶、密度、圆角
- ❌ 抄它的版式、文案、图片
- 参考图要说明「带什么、丢什么」：
  - 「带信息层级和密度，丢配色」
  - 「带卡片结构，丢字体」

---

## 反模式

| 反模式 | 后果 |
|---|---|
| 参考太多（>3 个） | 互相打架，提取不出主色 |
| 只看感觉不记数值 | 等于没提取 |
| 抄版式不学规律 | 侵权 + 不像自己的产品 |
| 提取了不写进简报 | 生成时用不上 |
| 假装提取过 | 用户以为准了，其实不准 |

---

## 检查清单

- [ ] 参考 ≤3 个
- [ ] 提取了数值（色板/字阶/圆角/间距/密度）
- [ ] 写进了《设计规范简报》，注明来源
- [ ] 没照抄版式
- [ ] 没给参考时明确告知用户
