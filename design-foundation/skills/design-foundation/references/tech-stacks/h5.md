# 纯 H5

**一句话**：跑在浏览器 / WebView 里的网页应用。**移动端 H5 的设计基准也是 375px**，不是 1440。

---

## 一、设计稿基准（⚠️ 最容易搞错）

| 场景 | 基准 | 说明 |
|---|---|---|
| **移动端 H5** | **375px** | 手机浏览器、微信内嵌、App WebView |
| **移动端 H5（2x 交付）** | 750px | 有些团队按 2x 出稿 |
| **响应式 H5（含平板）** | 375px 起 | 用 vw/rem 适配 |
| **PC 网站** | 1440px | 完全不同的场景 |

> ⚠️ **重点**：**H5 不是只有 1440**。手机 H5 的基准是 **375px**，和移动端一致。设计 H5 时按 375 出稿。

---

## 二、单位选择

| 单位 | 适用 | 说明 |
|---|---|---|
| **rem** | 响应式布局 | 需设根字号（`html { font-size }`） |
| **vw / vh** | 全屏元素、字体 | 相对视口 |
| **px** | 固定尺寸 | 边框、小图标 |
| **%** | 流式布局 | 相对父元素 |

### 常见方案

**方案 A：rem + 动态根字号**
```css
html { font-size: calc(100vw / 375 * 16); }  /* 375 基准，1rem = 16px */
```

**方案 B：vw**
```css
.container { width: 100vw; padding: 4.27vw; }  /* 16px / 375 */
```

**方案 C：uni-app 的 rpx**（跨端项目）
- H5 端 rpx 会被转成 rem/vw

---

## 三、导航结构

**H5 没有系统导航，全部自己画。**

| 元素 | 建议高度 |
|---|---|
| 顶部导航栏 | **44px**（iOS 风格）或 56px |
| 底部 TabBar | **50–56px** |
| 状态栏 | 自己画或避开（约 20–44px） |

**注意**：
- 如果是 App 内嵌 WebView，要**预留状态栏高度**（或用 `safe-area-inset-top`）
- 微信内嵌 H5 顶部有微信导航栏，不需要自己画

---

## 四、与移动端的差异

| 项目 | 移动端（小程序/App） | H5 |
|---|---|---|
| 导航 | 系统提供 | **自己画** |
| 返回 | 系统手势/按钮 | 自己实现（或依赖浏览器） |
| 字体 | 系统字体 | 可自定义 Web Font |
| 能力 | 受限（各平台规范） | **更自由** |
| 性能 | 较好 | 依赖优化 |
| 热区 | 平台规范 | 建议 ≥44px |

---

## 五、响应式断点

| 断点 | 宽度 | 布局 |
|---|---|---|
| base | < 640px | 单列 |
| sm | ≥ 640px | 双列 |
| md | ≥ 768px | 侧边栏 |
| lg | ≥ 1024px | 12 栏 |

**移动端 H5 通常只做 base 档**（< 640px），除非要适配平板。

---

## 六、常见坑

| 坑 | 说明 | 解法 |
|---|---|---|
| **用 1440 基准设计 H5** | 手机上字太小 | 用 375 基准 |
| **根字号没设** | rem 全部失效 | 明确 `html { font-size }` |
| **300ms 点击延迟** | 旧浏览器有 | 用 `touch-action: manipulation` 或 fastclick |
| **100vh 问题** | 移动端浏览器地址栏导致 | 用 `100dvh` 或 JS 计算 |
| **安全区** | iPhone 底部被遮挡 | `env(safe-area-inset-bottom)` |
| **图片模糊** | 没提供 2x 图 | 提供 `@2x` 或用 `srcset` |
| **字体加载闪烁** | Web Font 未加载 | `font-display: swap` |

---

## 七、设计交付要点

- **基准说清**：375px（不是 1440）
- **单位说清**：rem 还是 vw？根字号是多少？
- **导航说清**：自己画还是用系统？
- **安全区**：是否要适配 iPhone 刘海和 Home Indicator
- **断点**：是否只做移动端，还是要适配平板
