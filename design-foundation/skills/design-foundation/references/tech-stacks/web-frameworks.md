# Web 前端框架（PC 网站 / 管理后台）

**注意区分**：这里是 **PC 端网站**（1440 基准），不是移动端 H5（375 基准）。

---

## 一、设计基准

| 项目 | 数值 |
|---|---|
| 画板基准 | **1440px**（主流）或 1280px |
| 单位 | px / rem |
| 内容最大宽 | **1200–1280px** |
| 栅格 | 12 栏 |
| 断点 | sm 640 / md 768 / lg 1024 / xl 1280 / 2xl 1536 |

---

## 二、常用框架与 UI 库

| 框架 | 生态 | 常用 UI 库 |
|---|---|---|
| **React** | 最大 | Ant Design、MUI、shadcn/ui、Chakra UI、Mantine |
| **Vue 3** | 国内主流 | Element Plus、Ant Design Vue、Naive UI、Vant（移动） |
| **Next.js** | React 全栈 | 同 React + Tailwind |
| **Nuxt** | Vue 全栈 | 同 Vue + Tailwind |
| **Svelte / SvelteKit** | 新兴 | Skeleton、shadcn-svelte |
| **Angular** | 企业级 | Angular Material、NG-ZORRO |

**设计时要考虑**：项目用了哪个 UI 库，设计稿就要贴合它的组件规范。

---

## 三、后台管理系统的特殊规范

| 项目 | 建议 |
|---|---|
| 侧边栏宽度 | **240–260px**（可收起 64px） |
| 顶栏高度 | **56–64px** |
| 内容区边距 | 16–24px |
| 表格行高 | 48–56px |
| 卡片圆角 | 8–12px |

**布局模式**：
```
┌────────┬─────────────────────────┐
│        │  顶栏（面包屑 + 用户）    │
│ 侧边栏 ├─────────────────────────┤
│        │                         │
│ 240px  │  内容区（最大宽 1200）   │
│        │                         │
└────────┴─────────────────────────┘
```

---

## 四、与移动端的差异

| 项目 | 移动端 | PC Web |
|---|---|---|
| 画板 | 375 / 390 | 1440 |
| 导航 | 顶部/底部 | 顶部水平 + 侧边栏 |
| 交互 | 触摸 | 鼠标 + 键盘 |
| 状态 | 无 hover | **hover / focus** |
| 信息密度 | 低 | **高** |
| 布局 | 单列 | **多列 / 栅格** |
| 最大宽 | 无（全屏） | **1200–1280px** |

**设计影响**：
- 不要直接把移动端布局放大
- 要考虑 hover 态（表格行高亮、按钮变化）
- 表格可以展示更多列
- 信息密度可以更高

---

## 五、常用组件库的设计规范

| UI 库 | 设计特点 |
|---|---|
| **Ant Design** | 企业级、克制、蓝色主色、圆角 6px |
| **Element Plus** | 简洁、蓝色主色、圆角 4px |
| **MUI** | Material Design 3、圆角 4–8px |
| **shadcn/ui** | 高度可定制、Tailwind、无默认风格 |
| **Arco Design** | 字节、圆角 4px、色彩丰富 |
| **Naive UI** | TS 友好、主题可配 |

**设计建议**：
- 如果项目用 Ant Design，**直接按 Ant Design 的规范设计**，不要自己造
- 组件的尺寸、间距、圆角都跟随 UI 库

---

## 六、设计交付要点

- 基准 1440px，内容最大宽 1200–1280px
- 12 栏栅格，gutter 24px
- 响应式断点
- hover / focus 态齐全
- 与项目 UI 库规范对齐
- 表格、表单的密度规范
