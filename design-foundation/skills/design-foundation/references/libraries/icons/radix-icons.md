# Radix Icons

| 项目 | 内容 |
|---|---|
| 许可 | MIT |
| 商用 | ✅ 免费可商用 |
| 数量 | 300+ |
| 风格 | 线性、15px 栅格 |
| 权重 | 1 |
| 字体图标 | ❌ 无官方字体包，只有 SVG |
| Figma 插件 | ❌ 无 |
| 仓库 | `radix-ui/icons` |

**安装**：`npm i @radix-ui/icons`

**特点**
- Radix UI 团队出品，与 Radix 组件库风格一致
- 15×15 栅格（比主流的 24px 更小，适合紧凑界面）
- 只有 SVG，无框架组件包

**适合**：Radix UI 项目、紧凑界面

**不适合**：需要字体图标、需要大量图标

**来源**：https://www.radix-ui.com/icons
