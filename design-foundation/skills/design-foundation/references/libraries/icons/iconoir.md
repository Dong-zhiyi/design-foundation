# Iconoir

| 项目 | 内容 |
|---|---|
| 许可 | MIT |
| 商用 | ✅ 免费可商用 |
| 数量 | 1600+（含 288 个 solid 变体） |
| 风格 | 线性、轻量 |
| 权重 | 1（outline，部分有 solid） |
| 字体图标 | ❌ 无官方字体包，只有 SVG / 组件 |
| Figma 插件 | ❌ 无 |
| 仓库 | `iconoir-icons/iconoir` |

**安装**：`npm i iconoir`（或 `iconoir-react` / `@iconoir/vue` / `iconoir-react-native`）

**特点**
- 24×24 栅格，线条轻量
- 开源社区维护，免费可商用
- 提供 React / Vue / React Native / Flutter 库

**适合**：轻量线性风格、多框架项目

**不适合**：小程序（无字体包）、需要 Figma 插件

**来源**：https://iconoir.com
