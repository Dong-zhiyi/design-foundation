# Bootstrap Icons

| 项目 | 内容 |
|---|---|
| 许可 | MIT |
| 商用 | ✅ 免费可商用 |
| 数量 | 2000+ |
| 风格 | 轻量、16px 栅格 |
| 权重 | 2（outline / filled） |
| 字体图标 | ✅ `font/bootstrap-icons.min.css`（含 CDN） |
| Figma 插件 | ❌ 无 |
| 仓库 | `twbs/icons` |

**安装**：`npm i bootstrap-icons`

**特点**
- Bootstrap 官方图标库，但不依赖 Bootstrap，可独立使用
- 原生 16px 栅格，小尺寸清晰
- 提供 SVG、SVG Sprite、Icon Font、CSS、Sass 全套

**适合**：无框架项目、需要 iconfont、轻量场景

**不适合**：非 Bootstrap 项目可能风格略突兀；无 Figma 插件

**来源**：https://icons.getbootstrap.com
