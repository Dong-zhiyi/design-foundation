# IconPark

| 项目 | 内容 |
|---|---|
| 许可 | Apache-2.0 |
| 商用 | ✅ 免费可商用 |
| 数量 | 2000+（2600+ 基础图标） |
| 风格 | 字节跳动出品、多风格 |
| 权重 | 4 主题（outline / filled / two-tone / multi-color） |
| 字体图标 | ❌ 无官方字体包，只有 SVG / 组件 |
| Figma 插件 | ❌ 无 |
| 仓库 | `bytedance/IconPark` |

**安装**：`npm i @icon-park/react`（或 `/vue` / `/vue-next` / `/svg`）

**特点**
- 一套 SVG 通过改 fill/stroke 属性变 4 种主题
- 提供 React / Vue2 / Vue3 / 纯 SVG 包
- 字节跳动商用产品广泛使用

**适合**：需要多主题、React/Vue 项目

**不适合**：小程序端（无字体包）、需要 Figma 插件

**来源**：https://iconpark.oceanengine.com
