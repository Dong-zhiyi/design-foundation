# Octicons

| 项目 | 内容 |
|---|---|
| 许可 | MIT |
| 商用 | ✅ 免费可商用 |
| 数量 | 200+ |
| 风格 | GitHub 风格 |
| 权重 | 1 |
| 字体图标 | ❌ **官方已移除字体**（GitHub Issue #108 → PR #117），仅有非官方 `octicons-webfont` |
| Figma 插件 | ❌ 无 |
| 仓库 | `primer/octicons` |

**安装**：`npm i @primer/octicons`（或 `@primer/octicons-react`）

**特点**
- GitHub 官方图标，风格与 GitHub 产品一致
- **官方已弃用字体版本**（GitHub 自己改用 SVG）
- 社区有非官方字体包 `octicons-webfont`（基于 octicons 9.6.0）

**适合**：GitHub 风格产品、开发者工具

**不适合**：需要 iconfont 的项目（官方已移除）、需要大量图标

**来源**：https://primer.style/foundations/icons
