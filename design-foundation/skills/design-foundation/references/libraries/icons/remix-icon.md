# Remix Icon

| 项目 | 内容 |
|---|---|
| 许可 | Apache-2.0 |
| 商用 | ✅ 免费可商用 |
| 数量 | 3200+ |
| 风格 | 线性、中性、中文友好 |
| 权重 | 2（line / fill） |
| 字体图标 | ✅ `remixicon/fonts/remixicon.css` |
| Figma 插件 | ❌ 无 |
| 仓库 | `Remix-Design/RemixIcon` |

**安装**：`npm i remixicon`，然后 `import 'remixicon/fonts/remixicon.css'`

**特点**
- 中文文档友好，国内 CDN 快
- 24×24 栅格，line / fill 双版本
- 同时提供 SVG 和字体包

**适合**：中文项目、需要 iconfont、国内部署

**来源**：https://remixicon.com
