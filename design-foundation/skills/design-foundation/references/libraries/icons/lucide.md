# Lucide

| 项目 | 内容 |
|---|---|
| 许可 | ISC（含 Feather 的 MIT 部分） |
| 商用 | ✅ 免费可商用 |
| 数量 | 1600+ |
| 风格 | 线性、圆润、现代（24×24 栅格） |
| 权重 | 1 种（可调 stroke-width） |
| 字体图标 | ❌ 无官方字体包，只有 SVG / 组件 |
| Figma 插件 | ✅ 有 |
| 仓库 | `lucide-icons/lucide` |

**安装**：`npm i lucide` / `lucide-react`

**特点**
- Feather Icons 的社区维护分支，风格更现代
- shadcn/ui 的默认图标库
- 不支持品牌 logo（官方明确拒绝）

**适合**：通用产品、中性风格、需要 Figma 插件的场景

**不适合**：小程序端（无官方 iconfont，要自己转）

**来源**：https://lucide.dev
