# Heroicons

| 项目 | 内容 |
|---|---|
| 许可 | MIT |
| 商用 | ✅ 免费可商用 |
| 数量 | 300+/风格 |
| 风格 | 极简、手工打磨 |
| 权重 | 4（outline / solid / mini 20px / micro 16px） |
| 字体图标 | ❌ 无官方字体包，只有 SVG / 组件 |
| Figma 插件 | ❌ 无 |
| 仓库 | `tailwindlabs/heroicons` |

**安装**：`npm i @heroicons/react`（或 `@heroicons/vue`）

**特点**
- Tailwind Labs 出品，质量高、风格极简
- 有专门的 20px 和 16px 小尺寸版本（不是缩放，是重新绘制）
- 数量少，覆盖长尾要配合其他库

**适合**：极简风格、Tailwind 项目、小尺寸场景

**不适合**：小程序（无字体包）、需要大量图标的场景

**来源**：https://heroicons.com
