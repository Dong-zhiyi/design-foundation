# Fluent System Icons

| 项目 | 内容 |
|---|---|
| 许可 | MIT |
| 商用 | ✅ 免费可商用 |
| 数量 | 2000+ |
| 风格 | 微软 Fluent 设计体系 |
| 权重 | 2（Regular / Filled，另有 Light / Color 子集） |
| 字体图标 | ✅ 有官方字体实现（仓库 PR #438 已合并，`@fluentui/react-icons` 支持切换到字体实现，含 woff/woff2） |
| Figma 插件 | ❌ 无 |
| 仓库 | `microsoft/fluentui-system-icons` |

**安装**：`npm i @fluentui/react-icons`（或 Android/iOS/Flutter 包）

**特点**
- 微软 Fluent 设计体系的官方图标
- 支持 RTL（方向性图标有独立版本）
- 三种渲染方式：内联 SVG（默认）、**Icon font**、SVG sprite
- 有配套的子集化 webpack 插件

**适合**：微软风格产品、需要 Fluent 一致性、需要字体实现

**来源**：https://learn.microsoft.com/design/fluent-2/iconography/
